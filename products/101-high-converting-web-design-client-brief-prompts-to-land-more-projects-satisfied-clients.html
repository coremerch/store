101 High-Converting Web Design Client Brief Prompts to Land More Projects & Satisfied Clients

client brief prompts for web designers ? 40 prompts.

  1. List the top 5 business goals the client wants to achieve with their new website in 2024 (e.g., increase sales, reduce bounce rate, build brand authority).
  2. Specify the exact target audience demographics (age, location, income level, interests) the client wants to attract with their website redesign.
  3. Describe the 3 most important user personas the client wants the website to serve, including their pain points and motivations.
  4. Identify the 5 key competitors the client wants their website to outperform in terms of design, UX, and conversion rates.
  5. Ask the client to provide 3 examples of websites they admire and explain why they want their site to look and function similarly.
  6. Request a list of 5 specific features the client wants included in the new website (e.g., e-commerce, booking system, live chat, newsletter signup).
  7. Define the primary call-to-action (CTA) the client wants visitors to perform (e.g., 'Buy Now,' 'Sign Up,' 'Get a Free Quote').
  8. Ask the client to describe their brand voice and personality in 3 adjectives (e.g., professional, playful, minimalist).
  9. Request the client?s brand color palette in HEX codes and their preferred color mood (e.g., vibrant, muted, monochrome).
  10. Ask for the client?s top 3 font preferences for headings, body text, and buttons (e.g., Open Sans, Playfair Display, Montserrat).
  11. Specify whether the client wants a mobile-first, desktop-first, or responsive design approach.
  12. Ask the client to provide their existing logo files in vector format (AI, EPS, SVG) for consistency.
  13. Request the client?s brand guidelines or any existing style guides they want the new website to adhere to.
  14. Identify the 3 most important pages the client wants to prioritize in the redesign (e.g., Homepage, About Us, Services).
  15. Ask the client if they have any specific design trends they want to incorporate or avoid (e.g., dark mode, parallax scrolling, 3D elements).
  16. Request a list of 5 must-have images or graphics the client wants to feature on the website (e.g., product photos, team headshots, infographics).
  17. Ask the client if they have a preferred layout style for their homepage (e.g., hero section, grid, asymmetrical).
  18. Specify the client?s preferred navigation structure (e.g., mega menu, hamburger menu, sidebar navigation).
  19. Request the client?s existing website URL and access to their Google Analytics account for data analysis.
  20. Ask the client if they want to integrate any third-party tools or APIs (e.g., CRM, email marketing, social media feeds).
  21. Specify the client?s budget range for the project to ensure alignment on pricing expectations.
  22. Ask the client to provide a timeline for the project, including key milestones and deadlines.
  23. Request the client?s preferred communication method and frequency for updates (e.g., weekly emails, Slack, Zoom calls).
  24. Ask the client if they have any specific accessibility requirements (e.g., WCAG compliance, screen reader compatibility).
  25. Specify whether the client wants a one-page scroll design, multi-page layout, or a hybrid approach.
  26. Ask the client if they want to include a blog or news section and how frequently they plan to update it.
  27. Request the client?s social media profiles to ensure cross-platform branding consistency.
  28. Identify the 5 most important metrics the client wants to track post-launch (e.g., traffic, conversions, time on page).
  29. Ask the client if they want to include any interactive elements (e.g., quizzes, calculators, sliders).
  30. Specify the client?s preferred image file formats for uploads (e.g., JPEG, PNG, WebP) and compression preferences.
  31. Ask the client if they want to include a testimonials or case studies section and provide examples if available.
  32. Request the client?s preferred loading speed expectations and any optimization strategies they want to prioritize.
  33. Identify the 3 most important pages the client wants to A/B test post-launch for performance improvements.
  34. Ask the client if they want to include a membership or subscription feature and outline the desired functionality.
  35. Specify the client?s preferred hosting provider and domain registrar for seamless setup.
  36. Ask the client if they want to include a search functionality and how advanced it should be (e.g., basic, faceted search).
  37. Request the client?s preferred language(s) for the website and any localization requirements (e.g., multilingual support).
  38. Identify the 5 most important pages the client wants to include in their footer (e.g., contact info, sitemap, social links).
  39. Ask the client if they want to include a 404 error page and provide examples or guidelines for design and messaging.
  40. Specify the client?s preferred contact form fields and any integrations they want with CRM or email tools.
