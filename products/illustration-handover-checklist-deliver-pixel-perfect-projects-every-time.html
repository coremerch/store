Illustration Handover Checklist: Deliver Pixel-Perfect Projects Every Time

handover checklist for illustrators for hire ? 25 steps.

  1. Confirm final deliverables list with client (file formats, resolution, color modes)
  2. Provide source files (AI, EPS, PSD, SVG) with organized layers
  3. Include custom brushes, swatches, and color palettes used in the project
  4. Deliver original vector files with editable paths and anchor points
  5. Provide high-resolution raster files (PNG, TIFF, JPEG) at 300 DPI minimum
  6. Include web-optimized versions (72 DPI, optimized PNG/JPG)
  7. Share color profiles (sRGB IEC61966-2.1 for web, CMYK for print)
  8. Provide fonts used (or convert text to outlines if client requests)
  9. Include a style guide with Pantone, HEX, RGB, and CMYK color codes
  10. Deliver client-specific branding assets (logos, icons, social media kits)
  11. Provide any animation files (Lottie, GIF, MP4) if motion graphics were included
  12. Include a README file with file naming conventions and folder structure
  13. Provide a version history log showing revisions and iterations
  14. Share any 3D model files (OBJ, FBX, STL) if 3D elements were used
  15. Include a usage rights document outlining licensing and permissions
  16. Provide contact sheet or preview images for easy client review
  17. Deliver any custom patterns, textures, or seamless tiles created
  18. Include client-specific guidelines (e.g., safe zones, bleed areas for print)
  19. Provide a print-ready PDF with crop marks and bleed if applicable
  20. Share any AI-generated assets with clear attribution if required
  21. Include a list of all third-party assets used (with licenses and links)
  22. Provide social media-ready files with platform-specific dimensions
  23. Deliver a final invoice and payment receipt for the project
  24. Include a feedback form template for client post-project review
  25. Share a post-project checklist for client self-audit before launch
