The Ultimate Web Design Client Brief Generator: 40 Ready-to-Use Prompts for Clear, High-Value Projects

client brief prompts for web designers ? 40 prompts.

  1. List the top 3 business goals the client wants to achieve with this website (e.g., increase sales, generate leads, improve brand awareness).
  2. Specify the primary target audience for the website, including demographics (age, gender, location) and psychographics (interests, pain points, online behavior).
  3. Define the main user actions the website should facilitate (e.g., book a consultation, download an eBook, purchase a product, sign up for a newsletter).
  4. Describe the client?s existing brand identity, including colors, fonts, logo usage guidelines, and tone of voice for copywriting.
  5. Provide examples of 3-5 competitor websites the client likes (or dislikes) and explain why.
  6. Outline the client?s preferred website structure, including mandatory pages (e.g., Home, About, Services, Contact, Blog) and any special sections (e.g., testimonials, case studies, FAQ).
  7. Indicate whether the client wants a single-page website or a multi-page site, and justify the choice.
  8. Specify the content management system (CMS) the client prefers (e.g., WordPress, Webflow, Squarespace) and their technical comfort level.
  9. Clarify if the client has existing content (copy, images, videos) or if they need assistance with content creation.
  10. List all required integrations (e.g., payment gateways, CRM tools, email marketing platforms, analytics tools) and their specific functionalities.
  11. Define the client?s preferred navigation style (e.g., hamburger menu, mega menu, horizontal dropdown) and any mobile-specific navigation requirements.
  12. Specify the client?s expectations for loading speed and performance optimization (e.g., target load time, core web vitals score).
  13. Indicate whether the website needs to be multilingual and list the required languages.
  14. Clarify the client?s accessibility requirements (e.g., WCAG 2.1 AA compliance, screen reader optimization, keyboard navigation support).
  15. Provide the client?s preferred color palette and any colors that should be avoided, including hex codes.
  16. List the exact fonts the client wants to use for headings, body text, and buttons, including Google Fonts or custom font specifications.
  17. Specify the client?s desired layout style (e.g., minimalist, modern, corporate, playful) and provide 2-3 visual references.
  18. Define the client?s expectations for responsive design, including breakpoints for mobile, tablet, and desktop views.
  19. Indicate whether the client wants animations, micro-interactions, or parallax effects, and describe their preferred style (subtle, bold, playful).
  20. List any legal requirements the website must comply with (e.g., GDPR, CCPA, ADA, cookie consent banners).
  21. Specify the client?s budget range for the project and their preferred payment structure (e.g., milestone-based, hourly, fixed price).
  22. Clarify the client?s timeline, including project kickoff date, milestones, and final delivery deadline.
  23. Indicate whether the client has a preferred hosting provider or if they need recommendations (e.g., SiteGround, Bluehost, AWS).
  24. Provide the client?s preferred domain name and hosting setup (e.g., new domain, existing domain transfer, subdomain).
  25. Specify if the client wants a custom 404 page, custom error messages, or a maintenance mode page, and describe their preferred style.
  26. List all third-party services or APIs the website needs to connect with (e.g., Zapier, Mailchimp, Stripe).
  27. Clarify the client?s expectations for SEO optimization, including target keywords, meta descriptions, and on-page SEO requirements.
  28. Indicate whether the client wants a blog or news section, and specify the preferred layout and functionality (e.g., featured posts, categories, search).
  29. Specify the client?s preferred call-to-action (CTA) style and placement (e.g., above the fold, sticky header, pop-up modal).
  30. List any special features the client wants, such as a membership portal, event calendar, or live chat support.
  31. Clarify the client?s expectations for security measures (e.g., SSL certificate, firewall, regular backups, vulnerability scanning).
  32. Indicate whether the client wants social media integration (e.g., share buttons, embedded feeds, social login).
  33. Provide the client?s preferred style for imagery (e.g., illustrated, photographic, abstract) and any stock photo requirements.
  34. Specify if the client wants a dark mode or light mode toggle, and describe their preferred implementation.
  35. List any technical constraints (e.g., server limitations, legacy system compatibility, API rate limits) that may impact design decisions.
  36. Clarify the client?s expectations for analytics and reporting (e.g., Google Analytics setup, heatmaps, user session recordings).
  37. Indicate whether the client wants to include a newsletter signup form and specify the preferred design and placement.
  38. Provide the client?s preferred style for icons (e.g., line icons, filled icons, custom illustrations) and any icon library preferences.
  39. Specify if the client wants a cookie consent banner and describe their preferred design, messaging, and compliance requirements.
  40. Clarify the client?s expectations for ongoing support and maintenance (e.g., hourly rate, retainer, one-time fix).
