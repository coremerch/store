handover checklist for illustrators for hire ? 25 steps.

  1. Include a README file with project title, client name, and date delivered.
  2. Provide a high-resolution (300 DPI) final illustration file in PNG format.
  3. Deliver a layered PSD file with all groups, masks, and adjustment layers intact.
  4. Save vector files (AI/EPS) with all paths, anchor points, and swatches preserved.
  5. Export a transparent PNG with no background for web use.
  6. Create a color palette swatch file (ASE/ACO) with all used colors.
  7. Include a font list with names, weights, and download links if custom fonts were used.
  8. Provide a style guide with color codes (HEX, RGB, CMYK), typography, and spacing rules.
  9. Export a web-optimized JPEG (72 DPI) for quick client review.
  10. Include a PDF version of the final illustration for easy sharing and printing.
  11. Provide source reference images or mood boards used for inspiration.
  12. Create a folder structure with subfolders labeled ?Final?, ?Source?, and ?Extras?.
  13. Include a Changelog file detailing revisions made during the project.
  14. Deliver a print-ready CMYK version (300 DPI) if the client needs physical output.
  15. Provide social media-optimized versions (1080x1080, 1080x1350, etc.) of the illustration.
  16. Include a brief project summary with client goals, challenges, and solutions.
  17. Export an animated GIF or MP4 (if applicable) for motion-friendly platforms.
  18. Provide a list of all Illustrator brushes and textures used, with download links.
  19. Include a client-focused usage guide for the delivered files (e.g., ?Use PNG for web, AI for edits?).
  20. Deliver a low-resolution preview (72 DPI) in JPEG for quick client feedback loops.
  21. Include contact information for future design inquiries or revisions.
  22. Provide a licensing agreement file outlining usage rights and restrictions.
  23. Export a 1:1 aspect ratio square crop for social media thumbnails.
  24. Include a ?Next Steps? document with recommendations for future projects or upsells.
  25. Provide a customer satisfaction survey link to gather feedback post-delivery.
