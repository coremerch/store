Illustrator's Client Handover Checklist: Deliver Work Like a Pro & Get Repeat Hires

handover checklist for illustrators for hire ? 24 steps.

  1. Verify all client-provided assets (briefs, reference images, brand guidelines) are saved in a dedicated folder labeled 'Client Assets'.
  2. Confirm final deliverables match the agreed-upon file formats (e.g., PNG, SVG, PDF, AI) and resolutions (300 DPI for print, 72 DPI for web).
  3. Organize deliverables into a single folder named 'Final Artwork_[ClientName]_[ProjectName]' with no subfolders unless specified otherwise.
  4. Include a README.txt file in the deliverables folder with clear instructions on how to use the files (e.g., 'Use SVG for scalability, PNG for web previews').
  5. Provide a color palette document in PDF format, listing all HEX, RGB, CMYK, and Pantone values used in the project.
  6. Export and deliver low-resolution previews (JPG or PNG) for quick client approval before final delivery.
  7. Create a version history document (CSV or TXT) listing all major revisions with dates and brief descriptions of changes.
  8. Include a license agreement (PDF) outlining usage rights, attribution requirements, and any restrictions (e.g., exclusivity, territory).
  9. Generate a high-resolution mockup (PNG or JPEG) showing the illustration in at least 3 real-world contexts (e.g., packaging, app interface, print ad).
  10. Deliver layered source files (AI, PSD, or EPS) with all text converted to outlines and groups/layers labeled logically (e.g., 'Background', 'Character', 'Text').
  11. Include a font list (TXT or PDF) with all fonts used, their licenses, and download links if commercially available.
  12. Provide a style guide (PDF) summarizing key design decisions (e.g., color schemes, typography, character proportions) for future reference.
  13. Add a 'Change Log' sheet (Excel or Google Sheets) where clients can request adjustments, with columns for 'Description', 'Status', 'Date Requested', and 'Date Completed'.
  14. Export an optimized GIF or MP4 (if animation) showcasing the illustration in motion for digital platforms.
  15. Include a 'Quick Start Guide' (PDF) with step-by-step instructions for clients to implement the artwork (e.g., 'Import SVG into Canva by dragging and dropping').
  16. Deliver a 'Troubleshooting Guide' (PDF) addressing common issues (e.g., 'SVG not displaying correctly? Try opening in Illustrator first').
  17. Provide a contact sheet (PNG or JPEG) showing all alternate versions, sketches, or unused concepts with brief explanations.
  18. Include a 'Best Practices' document (PDF) for maintaining the integrity of the artwork (e.g., 'Avoid stretching vector artwork beyond 200%').
  19. Export an 'Accessibility Report' (PDF) detailing contrast ratios, alt-text suggestions, and screen-reader compatibility notes.
  20. Deliver a 'Social Media Kit' with pre-sized templates (Instagram Post, Twitter Header, LinkedIn Banner) featuring the illustration.
  21. Include a 'Print Specifications' sheet (PDF) for clients needing physical copies (e.g., 'Bleed: 3mm, Safe Zone: 5mm from edge').
  22. Provide a 'Future-Proofing' checklist (PDF) with recommendations for scaling, editing, or reusing the artwork (e.g., 'Use AI files for future edits').
  23. Add a 'Client Feedback Form' (Google Form link) to collect testimonials, referrals, or case study permissions post-delivery.
  24. Include a 'Thank You' email template (Word/Google Docs) with a link to the deliverables and a prompt for testimonials or social shares.
