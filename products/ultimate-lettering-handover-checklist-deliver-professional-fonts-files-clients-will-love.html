Ultimate Lettering Handover Checklist: Deliver Professional Fonts & Files Clients Will Love

handover checklist for lettering artists ? 25 steps.

  1. Deliver vector files in .ai, .eps, and .svg formats for maximum compatibility
  2. Include a high-resolution (300dpi) PNG preview for quick client approval
  3. Provide a transparent PNG with a white background for versatile use
  4. Include a transparent PNG with a transparent background for overlay applications
  5. Provide a PDF with all glyphs arranged in a grid for easy reference
  6. Deliver a TTF (TrueType Font) file for basic desktop use
  7. Include an OTF (OpenType Font) file for advanced typographic features
  8. Provide a WOFF (Web Open Font Format) file for web use
  9. Include an EOT (Embedded OpenType) file for legacy web compatibility
  10. Provide a variable font file if the lettering supports fluid typography
  11. Export and include a webfont kit with CSS for seamless integration
  12. Include a sample HTML file demonstrating font usage in a real layout
  13. Provide a Read Me text file with font installation instructions
  14. List all supported characters (uppercase, lowercase, numerals, symbols) in a separate document
  15. Include kerning pairs or spacing adjustments made during the project
  16. Provide a style guide documenting recommended usage (size, spacing, colors)
  17. Include examples of the lettering in different contexts (posters, business cards, social media)
  18. Provide a color palette file with CMYK and RGB values for print and digital use
  19. Include a Pantone color reference if the lettering uses a specific brand color
  20. Provide a scalable vector logo lockup if the lettering is part of a larger brand
  21. Include a license agreement outlining usage rights and restrictions
  22. Provide a credit template for the client to properly attribute the lettering artist
  23. Include a contact sheet with your branding and portfolio link for future work
  24. Provide a ZIP archive with all files organized in labeled subfolders
  25. Include a final invoice and payment confirmation for record-keeping
