Lettering Artist?s Digital Handover Checklist: Deliver Client-Ready Files Every Time

handover checklist for lettering artists ? 24 steps.

  1. Confirm project scope and deliverables (e.g., logo, quote, poster, social media graphics) in writing before starting work
  2. Provide a detailed timeline with milestones (e.g., sketch phase, vectorization, client review) and share it with the client
  3. Use a contract outlining ownership rights, usage permissions, and payment terms to protect both parties
  4. Deliver initial rough sketches or thumbnails in low resolution (e.g., 300px wide) for early client feedback
  5. Create a dedicated folder structure (e.g., /ClientName_Project/01_Sketches, /02_Vectors, /03_Finals) and maintain consistent naming conventions
  6. Export sketch files in PNG format with transparent backgrounds and include a timestamp in the filename (e.g., ClientName_Project_Sketch_20240515.png)
  7. Use vector software (e.g., Adobe Illustrator, Procreate, Affinity Designer) and ensure all files are saved in the original project format (.ai, .eps, .svg, .afdesign)
  8. Convert final lettering into a high-resolution vector file with editable text and anchor points (no merged paths)
  9. Create a separate locked background layer for any background elements to prevent accidental edits
  10. Export the final vector file in multiple formats: SVG (for web), EPS (for print), PNG (300 DPI, transparent), and PDF (vector-compatible)
  11. Include a font file (.otf or .ttf) if custom lettering uses unique typography; otherwise, convert text to outlines
  12. Generate a style guide with color codes (HEX, CMYK, RGB), font sizes, spacing rules, and usage examples for consistency
  13. Provide a mockup or rendering of the lettering in context (e.g., on a business card, poster, or social media template)
  14. Include a reference image or inspiration board showing the intended style or mood for the lettering
  15. Deliver a version optimized for web use (e.g., PNG with reduced file size under 1MB for fast loading)
  16. Include a print-ready version (300 DPI, CMYK color mode, bleed if required) with crop marks
  17. Provide a change log documenting all revisions made during the project (e.g., ClientName_Project_Revisions_20240515.pdf)
  18. Send a summary email with a direct download link to all project files and a quick start guide for implementation
  19. Offer to guide the client through implementing the lettering (e.g., uploading to a website builder or sending to a printer)
  20. Include a troubleshooting guide for common issues (e.g., font substitution errors, color mismatches, blurry exports)
  21. Provide a backup of all files in a compressed .zip folder labeled with the project name and date
  22. Include a copyright notice in the file metadata (e.g., ? 2024 ClientName. All rights reserved) and in the deliverables
  23. Ask the client to confirm receipt of all files and provide a final approval or feedback before closing the project
  24. Schedule a follow-up call or email within 7 days to ensure the client is satisfied and the files are working as intended
