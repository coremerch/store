Illustration Client Handover Checklist: Deliver Flawless Projects with Zero Stress

handover checklist for illustrators for hire ? 24 steps.

  1. Verify all client-provided reference images are high-resolution (300+ DPI) and saved in the project folder
  2. Confirm the project scope, including number of illustrations, styles, and deliverables, matches the signed contract
  3. Create a dedicated client folder on your cloud drive with clear subfolders for drafts, finals, and assets
  4. Label each illustration file with a naming convention (e.g., ClientName_IllustrationTitle_V01_Final.ai)
  5. Export all draft illustrations in the agreed-upon format (PNG, PDF, or native file) with transparent backgrounds
  6. Add a watermark to all drafts unless the client explicitly requests no watermark
  7. Include a text file in the drafts folder summarizing any pending client feedback or approvals needed
  8. Prepare a style guide (color palette, typography, character traits) as a PDF for client reference
  9. Test print quality by exporting a small test file (if applicable) and checking for pixelation or color shifts
  10. Ensure all final files are exported in the client?s requested formats (e.g., vector for logos, raster for web)
  11. Double-check that final files are flattened (if needed) and properly grouped/layered for easy client edits
  12. Provide a ReadMe.txt file with instructions on how to open, edit, or resize the files
  13. Include a copyright notice or license agreement in the final delivery package (if applicable)
  14. Generate a unique download link for the client using a service like Dropbox or WeTransfer with an expiration date
  15. Send a confirmation email with the download link, file specifications, and next steps (e.g., payment due)
  16. Schedule a follow-up call or email to ensure the client received and can access the files without issues
  17. Keep a backup of all project files for at least 3 months after delivery in a separate archive folder
  18. Document any client feedback or changes made during the project for future reference
  19. Update your portfolio with the final illustrations (with client permission) and tag them appropriately
  20. Request a testimonial or case study from the client for future marketing materials
  21. Send a thank-you email with a discount code for repeat clients or referrals
  22. Log the project in your CRM or spreadsheet with key details (client name, date, budget, delivery time)
  23. Review the checklist after each project to identify areas for improvement in your workflow
  24. Archive the checklist for this project in your templates folder for future use
