Ultimate Lettering Handover Checklist: 25 Steps to Flawless Client Deliverables & Happy Clients

handover checklist for lettering artists ? 25 steps.

  1. Verify project scope and client requirements before starting work
  2. Confirm file format requirements (AI, EPS, SVG, PNG, etc.)
  3. Set up a dedicated folder structure for project files
  4. Organize layers in Adobe Illustrator/Photoshop with clear naming conventions
  5. Create a master layer for guide lines and lock it
  6. Ensure all lettering strokes are vector paths, not rasterized
  7. Check that all letters are properly aligned and kerned
  8. Verify consistency in stroke weights across all characters
  9. Test readability of the lettering at various sizes (business card, poster, etc.)
  10. Export a high-resolution PNG for client preview with transparent background
  11. Provide a color palette reference with CMYK and RGB values
  12. Include a typography style guide with font specifications and usage rules
  13. Create a usage do's and don'ts document for the lettering
  14. Deliver a vector file with outlined paths for custom fonts
  15. Provide a version with live text if client may need to edit later
  16. Include a detailed invoice with itemized deliverables and pricing
  17. Send a USB drive or cloud link with all source files and extras
  18. Write a simple README file with instructions for opening and editing files
  19. Include a list of recommended software for opening vector files
  20. Provide contact information for follow-up questions or revisions
  21. Ask client to confirm receipt and satisfactory delivery of files
  22. Request a signed acceptance of deliverables and payment confirmation
  23. Archive project files with date-stamped backups in two different locations
  24. Send a thank-you email with a request for testimonial or portfolio feature
  25. Follow up one week later to ensure client is satisfied and gather feedback
