Client-Ready Lettering Handoff: 25-Step Digital Checklist for Flawless Deliverables

handover checklist for lettering artists ? 25 steps.

  1. Verify all lettering is aligned to the client?s specified baseline grid before exporting
  2. Confirm kerning pairs are optically balanced and not relying on auto-kerning
  3. Check for inconsistent optical sizes between uppercase and lowercase letters
  4. Ensure all special characters, ligatures, and alternate glyphs are included in the font file
  5. Export the lettering as a vector SVG with flattened paths and no hidden layers
  6. Create a high-resolution PNG (300 DPI) for quick client preview with transparent background
  7. Generate a PDF proof with all lettering variations (uppercase, lowercase, numerals, symbols) on a single page
  8. Include a separate PDF with only the finalized lettering artwork for print-ready use
  9. Provide a layered AI or PSD file with organized groups for each word/phrase in the design
  10. Include a text document listing all font names, sizes, and colors used in the project
  11. Add a readme.txt file with step-by-step instructions for installing and using custom lettering files
  12. Verify contrast ratios meet WCAG 2.1 standards for accessibility (min 4.5:1 for text)
  13. Check that all lettering is scaled proportionally and not distorted in any exported formats
  14. Ensure no stray anchor points or overlapping nodes exist in the vector paths
  15. Confirm all outlines are closed (no open paths) to prevent rendering issues
  16. Include a version history log with dates and descriptions of major revisions
  17. Provide a style guide snippet showing correct usage of the lettering in context
  18. Export a WebP version of the lettering for optimized web use with fallback PNG
  19. Create a mockup showing the lettering applied to a realistic surface (wood, paper, fabric)
  20. Include a color palette swatch file (ASE or ACO) with all brand colors used in the lettering
  21. Verify all text is converted to outlines if the client requested editable files to be disabled
  22. Add a notes file explaining any intentional design choices or client-requested adjustments
  23. Ensure all exported files are named clearly (e.g., 'ClientName_Lettering_Final.ai')
  24. Provide a short video walkthrough (MP4) demonstrating how to use the lettering files
  25. Include a troubleshooting guide for common issues like font embedding or path errors
