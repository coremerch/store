Illustrator?s Project Handover Checklist: Deliver Flawless Files Every Time

handover checklist for illustrators for hire ? 24 steps.

  1. Verify the client?s final brief, including project scope, deliverables, and any brand guidelines or style references.
  2. Confirm the exact file formats required (e.g., .AI, .EPS, .PNG, .PDF, .SVG) and their resolutions (e.g., 300 DPI for print).
  3. Ensure all vector files are saved in a compatible format (e.g., Adobe Illustrator CS6 or later).
  4. Outline all custom brushes, patterns, and graphic styles used in the project for easy reuse.
  5. Include a separate folder for fonts with a .txt file listing licensed, non-embedded fonts and their sources.
  6. Provide a color swatch file (.ASE) matching the project?s color palette for consistency.
  7. Export all rasterized elements (e.g., textures, effects) in the highest resolution requested by the client.
  8. Create a preview PDF with all final illustrations in one document, including client notes if applicable.
  9. Label every file clearly with the project name, date, and version number (e.g., ?ProjectName_Date_V1.ai?).
  10. Organize deliverables into a single ZIP file with a readme.txt outlining folder structure and file usage.
  11. Include a contact sheet or mood board showing initial sketches and approved concepts for reference.
  12. Provide a usage rights document specifying how the illustrations can be used (e.g., commercial, editorial, social media).
  13. Add a backup folder with layered source files (e.g., .PSD, .AI) for future edits or client revisions.
  14. Ensure all linked assets (e.g., stock images, external vectors) are properly licensed and credited.
  15. Check file naming conventions against client?s naming preferences (e.g., ?Logo_Primary.ai? vs. ?FinalLogo.ai?).
  16. Export a web-optimized version (e.g., .JPG at 72 DPI) for client previews if requested.
  17. Include a version history log in the readme.txt detailing major changes and approvals.
  18. Verify that all text elements are either outlined or provided in a separate editable file with fonts.
  19. Test print compatibility by exporting a CMYK color proof if the client requires physical output.
  20. Provide a short animation or GIF version of any illustrated sequences if motion graphics were part of the project.
  21. Include a style guide snippet for icons or recurring elements (e.g., line weights, colors).
  22. Add a transparency grid export (e.g., .PNG with checkerboard) for any elements with transparent backgrounds.
  23. Confirm with the client that all deliverables meet their initial expectations before final handover.
  24. Schedule a handover call or email to walk the client through the files and answer any questions.
