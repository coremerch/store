The Ultimate Lettering Handover Checklist: Deliver Professional Projects with Confidence

handover checklist for lettering artists ? 24 steps.

  1. Verify project scope matches client contract (e.g., logos, quotes, signage).
  2. Confirm final deliverables list (files, formats, quantities).
  3. Provide vector files (AI/EPS) with outlined strokes.
  4. Include original editable files (AI/PSD) with organized layers.
  5. Export high-resolution PNGs (300 DPI) for web use.
  6. Export transparent PNGs for web overlays.
  7. Create optimized JPEGs for print (CMYK color space).
  8. Provide SVG files for scalability (web/app use).
  9. Include font files or specify custom font usage rights.
  10. Document font names, sizes, and leading specs in a text file.
  11. List color codes (HEX, CMYK, Pantone) for each element.
  12. Provide a style guide with usage rules (minimum size, spacing, color variations).
  13. Include mockups showing final artwork in context (e.g., business cards, banners).
  14. Export a PDF proof with all deliverables and client notes.
  15. Organize files in a folder structure with clear naming (e.g., '01_Logos_Original', '02_Web_PNGs').
  16. Remove unused layers, paths, and hidden objects from files.
  17. Check all text is converted to outlines (no missing fonts).
  18. Ensure all strokes are expanded or outlined (no stroke-dependent designs).
  19. Verify bleed and safe zones are marked for print files.
  20. Include a README file with project details, client name, and date.
  21. Add a changelog documenting revisions and final approvals.
  22. Provide a contact sheet with high-res thumbnails of all deliverables.
  23. Test files on multiple devices/software (e.g., Adobe Illustrator, Affinity).
  24. Archive a backup copy of all files in a cloud storage (Google Drive, Dropbox).
