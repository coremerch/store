The Ultimate Lettering Handover Checklist: Deliver Client-Ready Projects Without Stress

handover checklist for lettering artists ? 25 steps.

  1. Verify project scope and deliverables with client contract
  2. Confirm final artwork dimensions and file formats requested
  3. Provide a high-resolution vector file (AI, EPS, or SVG)
  4. Include a transparent PNG version for web use
  5. Deliver a flattened JPG for quick client review
  6. Supply a layered PSD with all paths and effects intact
  7. Export a clean, organized Illustrator file with named layers
  8. Include a separate file for each color variant (CMYK and RGB)
  9. Provide a Pantone color swatch file with matching codes
  10. Include a typography guide with font names and usage rules
  11. List all custom brushes and tools used in the project
  12. Provide a color palette reference with hex, RGB, and CMYK values
  13. Include a spacing and kerning guide for consistent readability
  14. Deliver a baseline grid or guide file for alignment reference
  15. Provide a final mockup showing the lettering in context
  16. Include a usage rights document outlining licensing terms
  17. Confirm all client assets (fonts, references) are properly credited
  18. Test print output for color accuracy if physical delivery is required
  19. Provide a vector-based sketch or rough draft for historical reference
  20. Include a change log tracking all revisions made
  21. Provide a quick-start guide for clients to edit text in their own files
  22. Deliver a PDF with all deliverables listed and organized
  23. Include a contact sheet with your name, logo, and portfolio link
  24. Provide a follow-up checklist for client maintenance and updates
  25. Send a thank-you note with instructions for feedback submission
