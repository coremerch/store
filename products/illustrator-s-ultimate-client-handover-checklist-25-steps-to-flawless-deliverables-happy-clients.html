Illustrator's Ultimate Client Handover Checklist: 25 Steps to Flawless Deliverables & Happy Clients

handover checklist for illustrators for hire ? 24 steps.

  1. Confirm project scope and deliverables with the client in writing before starting work
  2. Create a project timeline with milestones and deadlines for each deliverable
  3. Agree on file format requirements (e.g., PNG, JPEG, SVG, AI, PDF) for final delivery
  4. Set clear expectations for file organization (e.g., named layers, grouped elements)
  5. Establish color mode (RGB for web, CMYK for print) based on client?s intended use
  6. Verify resolution requirements (e.g., 300 DPI for print, 72 DPI for web)
  7. Define acceptable file sizes for digital delivery (e.g., under 10MB for email)
  8. Agree on usage rights (e.g., commercial, non-commercial, exclusive) in the contract
  9. Request client?s brand guidelines, style references, or mood boards upfront
  10. Confirm typography usage rights if text is included in the illustration
  11. Provide client with a mid-project preview for feedback before finalizing
  12. Save all source files (e.g., .AI, .PSD, .EPS) with linked assets embedded
  13. Create a separate folder for final deliverables with clean, organized files
  14. Export and deliver low-resolution previews (e.g., JPEGs) for initial approval
  15. Provide high-resolution final files in the agreed formats and dimensions
  16. Include a README file with instructions for opening/editing files if needed
  17. Deliver a vector-based file (e.g., .AI, .SVG, .EPS) if the client may need to resize the artwork
  18. Provide a flattened version (e.g., PNG, JPEG) for immediate use in marketing materials
  19. Include alternative color variations (e.g., grayscale, monochrome) if requested
  20. Send a final invoice with payment terms and accepted payment methods
  21. Request a signed confirmation of receipt and approval from the client
  22. Archive a copy of all project files and communications for your records
  23. Follow up within 48 hours to ensure the client received and can access the files
  24. Send a thank-you note or feedback request to encourage repeat business
