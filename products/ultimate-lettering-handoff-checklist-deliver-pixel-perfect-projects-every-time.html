Ultimate Lettering Handoff Checklist: Deliver Pixel-Perfect Projects Every Time

handover checklist for lettering artists ? 25 steps.

  1. Provide all original vector files in .ai or .eps format with outlined strokes
  2. Include a separate 'working' folder with editable .ai files (un-outlined) for future edits
  3. Export high-resolution PNGs (300dpi) at multiple sizes (100%, 50%, 25%) for client preview
  4. Deliver a vector-based logo lockup if lettering is part of a branding project
  5. Include a style guide with font specifications (typeface name, weight, size ratios)
  6. Provide a color palette breakdown (CMYK, RGB, Pantone, and HEX codes)
  7. Include a spacing guide with minimum clear space requirements around the lettering
  8. Export a print-ready PDF with trim, bleed, and safe zones clearly marked
  9. Deliver a web-optimized version (SVG or optimized PNG) for digital use
  10. Include a black-and-white version with a transparent background for versatility
  11. Provide a reversed-out (white) version for dark backgrounds if applicable
  12. Export mockups showing the lettering on branded assets (business cards, banners, etc.)
  13. Include a 'do not use' list of fonts, colors, or styles to avoid in future applications
  14. Provide a usage rights document clarifying licensing terms for commercial use
  15. Include a master file with all linked assets (images, textures, gradients) organized in layers
  16. Deliver a typography hierarchy document showing how lettering scales in different contexts
  17. Provide a file naming convention guide (e.g., 'ClientName_Lettering_Primary.ai')
  18. Export a color-blind safe version if the project requires accessibility considerations
  19. Include a 'quick reference' cheat sheet with key specs for the client?s team
  20. Provide a list of recommended printers or embroiderers for physical applications
  21. Deliver a version with alternate ligatures or stylistic alternates if the font supports them
  22. Include a 'future-proofing' guide with tips for maintaining consistency over time
  23. Provide a source file with all custom lettering elements as individual paths/groups
  24. Export a version with alternate languages or scripts if the project is multilingual
  25. Include a 'thank you' note or small bonus asset (e.g., a custom icon) to surprise the client
