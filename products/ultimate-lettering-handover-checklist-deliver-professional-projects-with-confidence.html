Ultimate Lettering Handover Checklist: Deliver Professional Projects with Confidence

handover checklist for lettering artists ? 25 steps.

  1. Verify client's lettering style preferences (e.g., modern, vintage, script) in writing before starting.
  2. List all required lettering terms (e.g., ascenders, descenders, ligatures) in a glossary for client reference.
  3. Provide a style guide documenting font choices, stroke weights, and spacing rules.
  4. Include high-resolution reference images of inspirational lettering styles for context.
  5. Create a mood board with color palettes, textures, and typographic elements for visual alignment.
  6. Supply vector files in at least two formats (e.g., .ai, .eps, .svg) with all paths expanded.
  7. Export raster files (e.g., .png, .jpg) at 300 DPI for print-ready use in multiple color modes (RGB/CMYK).
  8. Include a layered PSD file if raster elements are part of the design, with clear group organization.
  9. Provide a PDF proof with lettering samples sized to actual use-case dimensions (e.g., business card, poster).
  10. Share a live-action video or animated GIF showing the lettering process from sketch to final design.
  11. Include a font list with licensing details for any custom or third-party typefaces used.
  12. Document kerning pairs and tracking adjustments made for optimal readability in the final lettering.
  13. Provide a scale reference (e.g., 1:1, 1:2) for lettering elements to assist with physical production partners.
  14. Include a hand-off document outlining file naming conventions (e.g., 'Logo_ClientName_V1.ai').
  15. Share a checklist of deliverables with deadlines and revision rounds agreed upon with the client.
  16. Provide contact information for file-related support (e.g., who to email for missing assets).
  17. Include a legal disclaimer about usage rights (e.g., commercial vs. personal use licenses).
  18. Supply a template for client edits (e.g., a labeled layer structure for text changes in vector files).
  19. Provide a list of recommended printers or manufacturers for lettering-specific projects (e.g., signage).
  20. Include a troubleshooting guide for common issues (e.g., font substitution, color shifts).
  21. Share a short video tutorial on how to open, edit, and use the provided files correctly.
  22. Provide a list of preferred software versions (e.g., Adobe Illustrator CC 2023) for compatibility.
  23. Include a backup folder with all source files, backups, and raw sketches in a ZIP archive.
  24. Add a section in the handover document with client testimonials or past project references.
  25. Provide a follow-up email template to send the client 48 hours after handover for feedback.
