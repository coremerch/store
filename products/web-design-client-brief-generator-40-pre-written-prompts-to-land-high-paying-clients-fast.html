Web Design Client Brief Generator: 40 Pre-Written Prompts to Land High-Paying Clients Fast

client brief prompts for web designers ? 40 prompts.

  1. What are the three primary goals of this website? (e.g., generate leads, sell products, showcase portfolio)
  2. Who is the ideal target audience? Include demographics like age, profession, and pain points.
  3. What are the top three competitors in this industry, and how should this site differentiate?
  4. What is the main call-to-action (CTA) that visitors should take after landing on the site?
  5. What existing branding elements (colors, fonts, logos) must the website incorporate?
  6. Are there any specific design styles (minimalist, brutalist, retro) that the client prefers?
  7. What is the client?s budget range for this project? (e.g., $1,000?$5,000, $10,000+)
  8. What is the desired timeline for completion? (e.g., 2 weeks, 1 month, 3 months)
  9. Should the website be responsive, adaptive, or mobile-first? Specify breakpoints.
  10. How many pages will the website have initially? List them (e.g., Home, About, Services, Contact).
  11. What type of content will populate each page? (e.g., blog posts, video, static text, image galleries)
  12. Does the client need a content management system (CMS)? If so, which one? (WordPress, Webflow, Squarespace, etc.)
  13. Are there any third-party integrations required? (e.g., payment gateways, CRM tools, live chat)
  14. What is the preferred color palette? Provide hex codes or references (e.g., #2C3E50, #E74C3C).
  15. What typography should be used? Specify font families and weights (e.g., 'Montserrat Bold for headings').
  16. Are there any accessibility requirements? (e.g., WCAG 2.1 AA compliance, screen reader support)
  17. Should animations or micro-interactions be included? If so, provide examples or mood boards.
  18. What is the client?s tone of voice? (e.g., professional, playful, corporate, friendly)
  19. Are there any legal or compliance needs? (e.g., GDPR, cookie consent, terms of service pages)
  20. Does the client have existing design assets (logos, brand guidelines, style guides)?
  21. What is the expected loading speed for the website? (e.g., under 2 seconds, optimized for SEO)
  22. Should the website include a blog or news section? If yes, how will it be structured?
  23. Does the client need a newsletter signup or email marketing integration?
  24. Are there any specific SEO keywords or phrases to target in the design?
  25. What is the client?s preferred hosting provider? (e.g., SiteGround, AWS, Vercel)
  26. Should the website include a membership or login system? If so, describe the user flow.
  27. Are there any age restrictions or content filters that need to be implemented?
  28. What is the client?s preferred method of communication during the project? (e.g., Slack, email, weekly calls)
  29. Does the client have any existing code or templates that should be reused or avoided?
  30. What is the client?s stance on pop-ups, overlays, or intrusive elements?
  31. Are there any specific animations or transitions the client wants to avoid?
  32. What is the client?s budget for ongoing maintenance or updates after launch?
  33. Does the client need a sitemap or user flow diagram before design begins?
  34. What is the client?s preferred method for handling revisions? (e.g., 3 rounds included, paid add-ons)
  35. Are there any industry-specific design trends the client wants to incorporate?
  36. Does the client need a favicon, social media assets, or other brand collateral?
  37. What is the client?s preferred method for collecting user feedback post-launch?
  38. Are there any specific security measures required? (e.g., SSL certificates, firewall protection)
  39. What is the client?s long-term vision for the website? (e.g., e-commerce expansion, multi-language support)
  40. Does the client have any existing analytics or tracking tools that need integration?
