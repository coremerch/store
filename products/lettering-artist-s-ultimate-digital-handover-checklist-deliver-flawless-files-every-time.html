Lettering Artist's Ultimate Digital Handover Checklist: Deliver Flawless Files Every Time

handover checklist for lettering artists ? 25 steps.

  1. Verify final lettering composition matches client?s brief (font style, letter proportions, spacing)?
  2. Check for consistent stroke weights across all letters and elements?
  3. Ensure no unintended overlapping or gaps between letters and decorative elements?
  4. Confirm all ligatures and special characters are included and properly spaced?
  5. Validate kerning pairs for readability and visual balance in all key combinations?
  6. Review baseline alignment consistency across uppercase, lowercase, and numerals?
  7. Check for uniform vertical and horizontal rhythm in letterforms?
  8. Confirm all swashes, alternates, and contextual glyphs are accessible and functional?
  9. Test ligature connections in all possible word combinations to prevent awkward joins?
  10. Verify optical adjustments (e.g., overshoots, underhangs) are consistent and intentional?
  11. Ensure all decorative flourishes and ornaments are vector-based and scalable without distortion?
  12. Check that all special characters (e.g., ampersands, exclamation points) are styled to match the design?
  13. Confirm color values (RGB, CMYK, Pantone) are accurate and match client?s brand guidelines?
  14. Validate file naming conventions follow client?s specified format (e.g., 'ClientName_Project_01.ai')?
  15. Export and provide all necessary file formats (AI, EPS, SVG, PNG, JPG) as requested?
  16. Include a read-only preview file (PDF or low-res image) for quick client reference?
  17. Provide a layer-organized source file with named groups (e.g., 'Base Letters', 'Flourishes', 'Background')?
  18. Include a separate file for any custom brushes or effects used in the design?
  19. Add a brief style guide document outlining font usage, spacing rules, and color codes?
  20. Provide a list of all licensed fonts used and their sources (with purchase links if applicable)?
  21. Confirm all linked images or assets are embedded or included in a separate folder?
  22. Check file compatibility with client?s preferred software (e.g., Illustrator, Procreate, Photoshop)?
  23. Include a quick-start guide for clients on how to use or modify the files?
  24. Verify file sizes and compression settings meet client?s delivery requirements?
  25. Send a final checklist confirmation email summarizing all delivered items and next steps?
