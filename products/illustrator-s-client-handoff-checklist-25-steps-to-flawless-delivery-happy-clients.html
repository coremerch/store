Illustrator's Client Handoff Checklist: 25 Steps to Flawless Delivery & Happy Clients

handover checklist for illustrators for hire ? 25 steps.

  1. Verify all client-provided references (mood boards, sketches, or style guides) are included in the project folder.
  2. Export final illustrations in all requested formats (PNG, JPEG, SVG, PDF, etc.) with correct color profiles (sRGB for digital, CMYK for print).
  3. Create a high-resolution JPEG preview at 300 DPI for client review in the project folder.
  4. Generate a low-resolution JPEG preview at 72 DPI for quick client sharing and approval.
  5. Organize files in a clear folder structure (e.g., 'Final_Assets', 'Source_Files', 'Exports').
  6. Name files using a consistent naming convention (e.g., 'ClientName_IllustrationType_Version.psd').
  7. Include a README.txt file with project details, client name, date, and contact information.
  8. Provide a list of all fonts used in the illustration, including licensing details (if applicable).
  9. Supply a color palette document (ASE, AI, or PDF) with HEX, RGB, and CMYK values for all used colors.
  10. Include a layer-by-layer PSD file with grouped and labeled layers for easy editing.
  11. Provide a flattened TIFF file for print-ready delivery (if applicable).
  12. Export a transparent PNG with no background for versatile use in client projects.
  13. Include a vector EPS file for scalability in client design projects.
  14. Deliver a vector AI file (Adobe Illustrator) with all original artwork and editable elements.
  15. Provide a PDF presentation of the final illustrations with a clean layout and client branding.
  16. Double-check all text elements for spelling, grammar, and font availability.
  17. Ensure all illustrations are aligned to the correct artboard dimensions as per client brief.
  18. Add a small watermark (if pre-approved) to low-res previews to prevent unauthorized use.
  19. Include a contact sheet with thumbnails of all final illustrations for quick reference.
  20. Provide a brief project summary document outlining client goals, revisions made, and final deliverables.
  21. Send a follow-up email with download links and clear instructions for accessing files.
  22. Offer a 48-hour revision window for any final tweaks or adjustments requested by the client.
  23. Include a feedback form link or contact details for post-delivery support and questions.
  24. Provide a final invoice with a breakdown of hours, services rendered, and payment terms.
  25. Schedule a post-project call or meeting to ensure client satisfaction and gather testimonials.
