  1. List the top 3 pain points your ideal client faces daily in their business.
  2. Describe the exact type of project your client is hiring for (e.g., website redesign, brand refresh, packaging design).
  3. Identify the client?s primary business goal for this project (e.g., increase online sales by 30%, rebrand for a market expansion).
  4. Note the client?s target audience demographics (age, gender, income level, location).
  5. Specify the client?s preferred communication style (e.g., email updates, weekly calls, Slack messages).
  6. Ask the client to provide 3-5 examples of designs they love and why.
  7. Request access to the client?s existing brand guidelines, style guides, or past marketing materials.
  8. Determine the client?s budget range for this project (e.g., $5K?$10K, $15K?$25K).
  9. Find out the client?s deadline for the project and any key milestones.
  10. Ask if the client has a preferred project management tool (e.g., Trello, Asana, Monday.com).
  11. Request the client?s brand voice and tone guidelines (e.g., professional, playful, authoritative).
  12. Clarify who the main decision-maker is for approvals and feedback.
  13. Ask if the client has any competitors they want to outshine with this project.
  14. Request examples of competitors? designs the client dislikes and why.
  15. Determine the client?s preferred file formats for final deliverables (e.g., AI, PDF, PNG, SVG).
  16. Ask if the client has any existing assets they want to incorporate (e.g., logos, photos, illustrations).
  17. Request the client?s preferred color palette and any colors they want to avoid.

  22. Ask if the client has any internal stakeholders who need to review the design before finalization.
  23. Determine the client?s preferred number of revision rounds included in the project scope.

  26. Ask if the client has any brand messaging or taglines that must be incorporated into the design.
  27. Determine the client?s preferred level of detail in design mockups (e.g., high-fidelity, wireframes, sketches).
  28. Ask if the client has any specific imagery or photography style preferences (e.g., minimalist, candid, stock photos).
  29. Request the client?s preferred social media platforms where the design will be used.
  30. Ask if the client has any specific print requirements (e.g., bleed, resolution, paper type).
  31. Determine the client?s preferred way to receive feedback (e.g., written comments, voice notes, in-person meetings).
  32. Ask if the client has any specific call-to-action (CTA) elements they want included in the design.

  34. Ask if the client has any specific animations or motion graphics they want included.
  35. Determine the client?s preferred way to handle intellectual property (IP) rights for the final design.
  36. Ask if the client has any specific industry standards or trends they want the design to reflect.
  37. Request the client?s preferred way to handle post-project support (e.g., maintenance, updates, training).
  38. Ask if the client has any specific tone for error messages or placeholder content in the design.
  39. Determine the client?s preferred way to handle client feedback during the design process (e.g., consolidated feedback, real-time collaboration).
