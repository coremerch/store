Web Designer?s Winning Client Brief Template: 40 High-Converting Prompts to Secure More Projects & Avoid Scope Creep

client brief prompts for web designers ? 40 prompts.

  1. List the client?s top 3 business goals and KPIs for the new website (e.g., increase sales by 30%, reduce bounce rate by 20%).
  2. Provide 3 examples of websites the client admires and explain why (specific elements, layout, or functionality).
  3. Share the client?s brand guidelines?logo files, color palette (HEX codes), typography (font names and weights), and any prohibitive colors or fonts.
  4. Define the target audience for the website in detail?age range, gender, location, profession, pain points, and online behavior.
  5. Specify the primary and secondary actions you want users to take on the homepage (e.g., ?Buy Now,? ?Subscribe to Newsletter,? ?Book a Consultation?).
  6. List all existing digital assets the client wants repurposed?blog posts, product images, videos, testimonials, case studies?and their current URLs.
  7. Clarify the client?s preferred tone of voice for all website copy?professional, casual, humorous, authoritative, etc.?with examples if available.
  8. Indicate whether the client requires multilingual support and if so, which languages and at what level (full translation, partial).
  9. State the number of pages the client expects in the initial scope and whether they plan to expand in the future (e.g., +5 pages in 6 months).
  10. Provide the client?s preferred project timeline?launch date, key milestones (design approval, development completion, QA testing), and any hard deadlines.
  11. Share the client?s budget range for the website project (even if rough) and note if they have a preference for fixed-price vs. hourly billing.
  12. List all third-party integrations required?payment gateways (Stripe, PayPal), CRM (HubSpot, Salesforce), email marketing tools (Mailchimp), chatbots (Intercom), etc.
  13. Specify if the client needs a content management system (CMS) and if they have a preference (WordPress, Webflow, Squarespace, custom).
  14. Describe any legal or compliance requirements the website must meet?GDPR, ADA accessibility, COPPA, industry-specific regulations (HIPAA for healthcare).
  15. Provide the client?s preferred method for feedback and approvals?email, Slack, Trello, Asana, or a dedicated client portal.
  16. Clarify if the client wants to maintain ownership of the final design files and source code post-project, or if they prefer a license agreement.
  17. List any competitors the client wants to benchmark against and key differentiators they want to highlight on the site.
  18. State whether the client requires a mobile-first design approach or if desktop-first is acceptable, including any specific mobile UX constraints.
  19. Specify the client?s hosting and domain preferences?do they have an existing domain and hosting provider, or do they need recommendations?
  20. Provide the client?s preferred project communication cadence?daily standups, weekly updates, bi-weekly reviews?and preferred channels (Zoom, Google Meet, Slack).
  21. List any technical constraints or preferences?browser compatibility (support for IE11?), performance benchmarks (load time under 2 seconds), or specific frameworks (React, Vue).
  22. Clarify if the client needs e-commerce functionality and if so, which platform they prefer (Shopify, WooCommerce, BigCommerce, custom).
  23. State whether the client wants to include a blog or news section and if they have existing content that needs to be migrated.
  24. Provide the client?s social media links and specify if they want social media integration (share buttons, live feeds, follow widgets).
  25. List any specific animations or micro-interactions the client wants to include (hover effects, parallax scrolling, loading animations).
  26. Clarify if the client needs a custom 404 error page, maintenance mode page, or other utility pages designed.
  27. State whether the client requires SEO optimization in the initial scope?on-page SEO, meta tags, schema markup, XML sitemap generation.
  28. Provide the client?s current website analytics data (Google Analytics, heatmaps) and any key insights they want to leverage in the redesign.
  29. List any third-party services or APIs the client wants to connect?Google Maps, payment processors, customer support tools, etc.
  30. Clarify if the client wants to include user-generated content features?reviews, ratings, comments, or forums.
  31. Specify the client?s preferred image and video style?professional photography, illustrations, animations, stock footage, or user-generated content.
  32. List any specific security measures the client requires?SSL certificates, two-factor authentication, data encryption, regular security audits.
  33. Clarify if the client needs a password-protected area or member login functionality for gated content or user accounts.
  34. Provide the client?s preferred color scheme for key pages (homepage, product pages, contact form) and any brand colors to avoid.
  35. State whether the client wants to include a newsletter signup form and if they have an existing email list to integrate.
  36. Clarify if the client needs a search functionality on the website and if they want to implement a custom search solution or third-party tool.
  37. List any specific accessibility standards the client wants to adhere to?WCAG 2.1 AA, Section 508, or other regional guidelines.
  38. Provide the client?s preferred method for collecting user feedback?contact forms, live chat, surveys, or social media links.
  39. Clarify if the client wants to include a live chat or chatbot feature and if they have a preferred provider (Drift, Zendesk, Drift).
  40. State whether the client needs a booking or scheduling system integrated into the website (Calendly, Acuity, custom).
