The Solo Designer?s Client Brief Blueprint: 40 High-Converting Prompts to Land Premium Projects & Avoid Scope Creep

client brief prompts for agency escapees going solo ? 40 prompts.

  1. List the client?s top 3 business goals (revenue, awareness, retention) and how they measure success for each.
  2. Identify the primary audience persona using job title, age range, pain points, and preferred communication channels.
  3. Ask for 3 direct competitors and explain what the client likes/dislikes about their visual branding.
  4. Request access to the client?s existing brand guidelines, fonts, and color palette files (PDF, Figma, or Adobe Libraries).
  5. Provide 3 examples of design styles the client admires (include links to Dribbble, Behance, or Pinterest boards).
  6. Ask for the client?s preferred tone of voice (professional, playful, minimalist) and 3 adjectives describing their brand personality.
  7. Clarify if the project is part of a larger campaign and if there are existing assets to maintain consistency.
  8. Request a signed scope of work document outlining deliverables, revisions, and payment terms before starting any work.
  9. Ask for the client?s budget range (e.g., $1,500?$3,000) and preferred payment schedule (50% upfront, 50% on delivery).
  10. Determine the project deadline and any external dependencies (e.g., client feedback, third-party integrations).
  11. Identify the key stakeholders involved in approvals and their preferred communication tools (Slack, Email, Loom).
  12. Ask for the CMS or platform the final design will live on (WordPress, Webflow, Shopify) and any technical constraints.
  13. Request brand assets in multiple formats (logo variations, high-res images, vector files) for reference.
  14. Clarify if the client has in-house designers or if all design work will be outsourced to you.
  15. Ask for 3 examples of past projects the client loved and why they resonated with their audience.
  16. Determine if the client wants a style guide or brand book created alongside the main deliverable.
  17. Request a list of 5 adjectives the client does NOT want associated with their brand (e.g., corporate, outdated).
  18. Ask for the client?s preferred file formats for final delivery (Figma, Sketch, PDF, PNG, SVG).
  19. Clarify if the client needs social media templates, email designs, or print-ready files included in the project.
  20. Identify any legal or compliance requirements (e.g., accessibility standards, copyright restrictions).
  21. Ask for the client?s preferred color palette and if there are any colors they want to avoid.
  22. Request a list of 3 pain points their audience currently faces that the design should address.
  23. Determine if the client has a brand story or mission statement that should influence the design direction.
  24. Ask for the client?s preferred typography hierarchy (e.g., H1, H2, body copy styles) and font preferences.
  25. Clarify if the client needs responsive design adaptations for mobile, tablet, or desktop views.
  26. Identify any third-party integrations (e.g., payment gateways, CRM tools) that the design must accommodate.
  27. Ask for the client?s preferred imagery style (photography, illustrations, abstract) and 3 example sources.
  28. Request a list of 5 brands the client admires for inspiration and what specifically they like about them.
  29. Determine if the client needs a mood board or wireframes before moving to the final design phase.
  30. Clarify if the client has a preferred design tool (Figma, Adobe XD, Sketch) for collaboration and feedback.
  31. Ask for the client?s preferred animation or micro-interaction style if applicable (e.g., parallax scrolling, hover effects).
  32. Identify any existing design assets that need to be redesigned or updated as part of the project.
  33. Request a list of 3 KPIs the client will use to measure the design?s impact post-launch.
  34. Ask for the client?s preferred method for receiving feedback (in-app comments, annotated PDFs, video calls).
  35. Clarify if the client needs SEO optimizations included in the design (e.g., alt text, schema markup).
  36. Determine if the client has a preferred project management tool (Trello, Asana, ClickUp) for tracking progress.
  37. Ask for the client?s preferred method for receiving final deliverables (Google Drive, Dropbox, WeTransfer).
  38. Identify any industry-specific design trends the client wants to incorporate or avoid.
  39. Request a list of 3 questions the client has about the design process that you can address upfront.
  40. Ask for the client?s preferred method for handling revisions (e.g., 2 rounds included, additional rounds at $X/hour).
