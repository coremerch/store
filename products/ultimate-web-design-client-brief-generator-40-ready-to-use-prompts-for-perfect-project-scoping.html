Ultimate Web Design Client Brief Generator: 40 Ready-to-Use Prompts for Perfect Project Scoping

client brief prompts for web designers ? 40 prompts.

  1. List the client?s business name, industry, and primary products/services offered.
  2. Specify the target audience?s demographics (age, gender, location, income level).
  3. Describe the client?s brand personality in 3-5 adjectives (e.g., modern, trustworthy, playful).
  4. Provide the client?s existing brand colors with hex codes or color names.
  5. List the client?s current fonts or preferred font styles for headings and body text.
  6. State the client?s main competitors and one key differentiator for their website.
  7. Define the primary goal of the website (e.g., sell products, generate leads, showcase portfolio).
  8. Specify the number of pages the website will need (e.g., Home, About, Services, Contact, Blog).
  9. List the required sections for the homepage (e.g., hero banner, features, testimonials, CTA).
  10. Describe any specific functionality needed (e.g., contact forms, booking system, e-commerce integration).
  11. Provide the client?s preferred style of imagery (e.g., stock photos, custom illustrations, abstract graphics).
  12. State whether the website needs to be mobile-responsive and optimized for all devices.
  13. Specify the client?s preferred navigation structure (e.g., horizontal menu, hamburger menu, multi-level dropdown).
  14. List any third-party integrations needed (e.g., Mailchimp, Google Analytics, social media feeds).
  15. Provide the client?s preferred layout for product/service pages (e.g., grid, list, carousel).
  16. State the client?s tone of voice for written content (e.g., formal, casual, humorous).
  17. Specify the client?s preferred call-to-action button style and color.
  18. List any existing content (text, images) that can be repurposed for the new website.
  19. State the client?s preferred loading speed expectations (e.g., under 3 seconds).
  20. Provide the client?s desired color scheme for the website (primary and secondary colors).
  21. Specify the client?s preferred font sizes for headings (H1, H2, H3) and body text.
  22. List any animations or micro-interactions the client wants to include (e.g., hover effects, parallax scrolling).
  23. State whether the website needs a blog or news section and its expected update frequency.
  24. Provide the client?s preferred method for handling customer inquiries (e.g., contact form, live chat, email).
  25. Specify the client?s desired placement for social media icons (e.g., header, footer, sidebar).
  26. List any legal requirements for the website (e.g., GDPR compliance, cookie consent banner).
  27. State the client?s preferred method for displaying pricing (e.g., static page, interactive calculator).
  28. Provide the client?s preferred style for buttons (e.g., flat, gradient, 3D).
  29. Specify the client?s desired layout for the footer (e.g., minimal, detailed with links, newsletter signup).
  30. List any specific SEO requirements (e.g., keyword targeting, meta descriptions, alt text for images).
  31. State the client?s preferred method for handling user feedback (e.g., surveys, contact form, chatbot).
  32. Provide the client?s preferred style for testimonials or reviews (e.g., carousel, grid, single highlight).
  33. Specify the client?s desired layout for team or staff profiles (e.g., cards, list, grid).
  34. List any specific accessibility requirements (e.g., screen reader compatibility, high contrast mode).
  35. State the client?s preferred method for handling 404 errors (e.g., custom page, redirect to home).
  36. Provide the client?s desired style for error messages or validation forms (e.g., inline, pop-up).
  37. Specify the client?s preferred method for handling user logins or memberships (e.g., simple login, social login).
  38. List any specific hosting or domain requirements (e.g., client-managed, designer-managed).
  39. State the client?s desired timeline for the project, including key milestones and deadlines.
  40. Provide the client?s preferred method for project communication (e.g., Slack, email, weekly calls).
