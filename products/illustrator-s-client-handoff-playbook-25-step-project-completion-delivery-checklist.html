Illustrator?s Client Handoff Playbook: 25-Step Project Completion & Delivery Checklist

handover checklist for illustrators for hire ? 25 steps.

  1. Confirm project scope and deliverables with the client before starting any work
  2. Document the agreed-upon color palette in a separate PDF or color swatch file
  3. Provide vector source files (AI, EPS, or SVG) with all layers and groups intact
  4. Include a high-resolution raster version (PNG or JPEG) at 300 DPI for web use
  5. Deliver a vector version optimized for print (CMYK color mode, 300 DPI)
  6. Offer a thumbnail-sized preview (under 2MB) for quick approvals
  7. Create a style guide summarizing fonts, colors, and spacing rules
  8. Include a vector version with all text converted to outlines (if applicable)
  9. Provide a locked version (flattened) for clients who need to prevent edits
  10. Deliver a detailed invoice with itemized services and payment terms
  11. Send a usage rights agreement outlining permitted uses and limitations
  12. Include a readme file with file naming conventions and folder structure
  13. Provide a version history log tracking revisions and client feedback
  14. Deliver a final presentation mockup in the intended context (e.g., packaging, app UI)
  15. Include all original sketch files or early concepts for reference
  16. Provide a font list with licensing details for any paid or custom fonts used
  17. Send a separate file with all custom brushes, textures, or patterns used
  18. Include a PDF summary of the project timeline and key milestones
  19. Deliver a final invoice receipt with payment confirmation and project ID
  20. Provide a client feedback form with clear instructions for revisions
  21. Include a backup folder with all exported assets in multiple formats
  22. Send a thank-you email with next steps for future collaborations
  23. Provide a quick-start guide (1-page cheat sheet) for easy file navigation
  24. Include a list of recommended printing or manufacturing partners (if applicable)
  25. Deliver a post-project survey to gather client feedback for improvement
