Ultimate Lettering Handover Checklist: Deliver Pixel-Perfect Files Clients Can Actually Use

handover checklist for lettering artists ? 25 steps.

  1. Provide all lettering designs in vector format (AI, EPS, SVG) at 100% scale
  2. Export each letter separately as individual SVG files with no grouping
  3. Include a master AI file with each letter on its own layer in alphabetical order
  4. Create a separate AI file with all letters combined as a single editable object
  5. Provide high-resolution PNG exports at 300 DPI for web use (transparent background)
  6. Include optimized PNG exports at 72 DPI for social media (transparent background)
  7. Provide a PDF with all designs at actual size for print reference
  8. Export a PDF with all designs scaled to common t-shirt print sizes (S-3XL)
  9. Include a style guide PDF with font names, sizes, and spacing specifications
  10. Provide color swatches in Pantone, CMYK, RGB, and HEX formats
  11. Document all custom ligatures, alternates, and contextual swashes with examples
  12. Include a character set showing all available glyphs in each style
  13. Provide spacing metrics (kerning pairs) for all common letter combinations
  14. Export a version with baseline grid overlays for easy alignment reference
  15. Include a version with optical size adjustments for different viewing distances
  16. Provide a version with each letter's anchor points clearly marked
  17. Document any special OpenType features used (ligatures, stylistic alternates)
  18. Include a version with each letter's path directions clearly visible
  19. Provide a version optimized for laser cutting or vinyl cutting with cut lines
  20. Include a version with each letter's bounding box measurements in millimeters
  21. Provide a version with each letter's center of gravity marked for balance
  22. Include a version with each letter's optical correction points highlighted
  23. Document any recommended pairing with existing fonts or design systems
  24. Provide a version with each letter's historical or cultural context notes
  25. Include a version with each letter's construction breakdown (strokes, serifs, terminals)
