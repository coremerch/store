Lettering Project Handoff Checklist: 25 Steps to Flawless Client Deliverables Every Time

handover checklist for lettering artists ? 25 steps.

  1. Verify client?s preferred file formats (AI, SVG, PNG, PDF) and resolution requirements before starting the project.
  2. Confirm the exact lettering style (modern, vintage, brush, graffiti, etc.) and any specific letterforms or ligatures needed.
  3. Check if the client has provided a reference style guide, mood board, or examples of desired lettering characteristics.
  4. Ensure you have the correct copy (text to be lettered) and confirm its accuracy and completeness with the client.
  5. Ask for any specific typography or font references that should influence the lettering design.
  6. Confirm the target medium (print, web, signage, merchandise) to adjust spacing, thickness, and details accordingly.
  7. Set up your canvas with the correct dimensions based on the delivery format (e.g., A4 for print, 1920x1080 for web).
  8. Establish baseline grid or guide lines for consistent letter proportions and spacing.
  9. Create a master artboard for the primary lettering design and duplicate it for variations or corrections.
  10. Sketch rough drafts of letterforms on paper first to refine shape, balance, and readability before digitalizing.
  11. Digitize the final sketch using a tablet and stylus, ensuring smooth, clean vector paths for scalability.
  12. Use a vector-based software (Adobe Illustrator, Affinity Designer, Procreate) to maintain sharp, scalable letterforms.
  13. Ensure all letterforms are converted to outlines or compound paths to avoid font dependency issues.
  14. Check for consistent stroke weights and optical adjustments (e.g., slightly thicker verticals in serifs).
  15. Adjust spacing between letters (kerning) and words (tracking) for optimal readability and visual flow.
  16. Create alternate versions (e.g., condensed, expanded, uppercase-only) if requested by the client.
  17. Test the lettering at multiple sizes (e.g., 12pt, 24pt, headline size) to ensure legibility.
  18. Provide a color palette breakdown with hex codes, CMYK, and RGB values if color is part of the design.
  19. Include a grayscale or black-and-white version for monochrome applications (e.g., engraving, embroidery).
  20. Add a background color or texture reference if the lettering is meant to sit on a non-white surface.
  21. Create a mockup showing the lettering in context (e.g., on a poster, t-shirt, or storefront sign).
  22. Export final files in the requested formats with appropriate color profiles (e.g., CMYK for print, sRGB for web).
  23. Organize deliverables in a folder structure (e.g., /Final_Vectors, /Rasters, /Mockups, /Extras) and label files clearly.
  24. Include a readme.txt or brief explanation document with usage notes, licensing terms, and your contact information.
  25. Conduct a final review for typos, misalignments, or visual inconsistencies before sending to the client.
