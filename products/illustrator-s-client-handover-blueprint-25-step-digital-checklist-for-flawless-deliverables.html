Illustrator's Client Handover Blueprint: 25-Step Digital Checklist for Flawless Deliverables

handover checklist for illustrators for hire ? 24 steps.

  1. Verify client?s preferred file format (AI, EPS, PNG, SVG, PDF, etc.) before starting work.
  2. Confirm the exact color mode (RGB for digital, CMYK for print) with the client.
  3. Check if the client needs layered files (AI/EPS) or flattened (PNG/PDF).
  4. Ensure all fonts used are either embedded or outlined in the final files.
  5. Collect client?s brand guidelines (hex codes, Pantone references, style rules).
  6. Ask for a list of deliverables (e.g., 3 final illustrations, 10 social media graphics).
  7. Request the final dimensions for each illustration (e.g., 1024x1024px, 1920x1080px).
  8. Confirm the resolution requirements (e.g., 300 DPI for print, 72 DPI for web).
  9. Ask if the client needs vector files (AI/EPS) for scalability or raster (PNG/JPG).
  10. Verify if the client requires source files (PSD, AI) for future edits.
  11. Check if the client needs alternate color versions (light/dark mode, accessibility compliance).
  12. Ask for a list of required file names (e.g., 'hero-illustration-v1.ai', 'logo-final.png').
  13. Confirm the file naming convention (e.g., 'ClientName-Illustration-Type-Version').
  14. Ensure all files are organized in a single folder with subfolders if needed (e.g., 'Final_Versions', 'Source_Files').
  15. Double-check that all files are named correctly without typos or incorrect versions.
  16. Test all files before sending to ensure they open correctly in the client?s preferred software.
  17. Include a README.txt file with instructions for opening/editing files.
  18. Provide a contact sheet with your contact info, invoice number, and project name.
  19. Verify if the client needs a style guide for future reference (e.g., icon set usage rules).
  20. Ask if the client needs export presets (e.g., 'Save for Web' settings for web use).
  21. Confirm the licensing terms (e.g., exclusive vs. non-exclusive, usage rights).
  22. Provide a final invoice summary with payment terms and due date.
  23. Ask for a signed off approval (email or digital) to confirm deliverables are accepted.
  24. Include a feedback deadline (e.g., 'Please review within 5 business days').
