Ultimate Lettering Handover Checklist: Client-Ready Deliverables Every Time

handover checklist for lettering artists ? 25 steps.

  1. Verify all lettering paths are expanded and converted to outlines with no live text remaining
  2. Ensure all anchor points are smooth and no auto-corners remain in Bezier curves
  3. Check for overlapping or touching letterforms that may cause printing issues
  4. Confirm baseline consistency across all words or phrases in the design
  5. Validate kerning pairs for readability at small sizes (min 12pt if print)
  6. Test optical kerning adjustments for each letter combination
  7. Adjust letter spacing (tracking) to match the intended visual hierarchy
  8. Create alternate spacing versions for different backgrounds (light/dark)
  9. Export a monoline version for screen use and a stylized version for print
  10. Generate a high-resolution (300dpi+) raster preview for quick client review
  11. Provide a vector-based mockup in a neutral background for portfolio use
  12. Include a style tile showing 3-5 key letter variations (uppercase, lowercase, numbers, punctuation)
  13. Deliver a usage guide with minimum size recommendations and safe zones
  14. Supply a color palette file (ASE/Swatch) with all brand-compliant lettering colors
  15. Offer a black-and-white version with 100% opacity for stamp or engraving
  16. Create a reversed-out version (white on black background) for dark-themed applications
  17. Include a grayscale version for laser engraving or etching purposes
  18. Provide a transparent PNG with a pixel-perfect 1px stroke for web overlays
  19. Export a bleed-ready version (3mm extra on all sides) for print production
  20. Generate a version with cut lines for vinyl or sticker applications
  21. Include a version with spaced-out letters for glow or neon sign mockups
  22. Provide a 3D mockup with depth and shadow for client presentations
  23. Add a version with animated wiggle effect for social media use (GIF/MP4)
  24. Include a license agreement specifying usage rights and attribution requirements
  25. Deliver all files in a zipped folder with clear naming conventions (e.g., 'ClientName_ProjectName_Lettering_V1.0')
