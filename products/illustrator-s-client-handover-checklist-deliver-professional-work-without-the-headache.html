Illustrator?s Client Handover Checklist: Deliver Professional Work Without the Headache

handover checklist for illustrators for hire ? 25 steps.

  1. Verify project scope matches contract agreement (deliverables, timeline, revisions).
  2. Confirm final deliverables match the agreed format (PNG, JPEG, SVG, PDF, AI, EPS, etc.).
  3. Ensure all files are in the correct color mode (RGB for digital, CMYK for print).
  4. Check file resolution: 300 DPI for print, 72?150 DPI for digital/web use.
  5. Organize files in a clearly labeled folder structure (e.g., 'Final_Artwork' and 'Client_Files').
  6. Include a 'Read_Me_First.txt' file with project title, client name, and your contact info.
  7. Provide a non-proprietary preview (low-res JPEG) for quick client approval before sending final files.
  8. Export transparent backgrounds for PNG/SVG files using the correct clipping path or alpha channel.
  9. Remove hidden layers, unused assets, and stray vector points from final AI/EPS files.
  10. Flatten all layers in Photoshop files and save as a layered PSD only if client requested editable layers.
  11. Include a style guide (typography, color codes, spacing) if applicable to the project.
  12. Supply alternate versions (e.g., square and landscape orientations) if the client requested variations.
  13. Attach a usage rights document outlining what the client can and cannot do with the artwork.
  14. Provide a revision log tracking changes made during the project for transparency.
  15. Send a high-resolution PDF for print-ready approval if the file is intended for commercial printing.
  16. Include metadata in files (title, author, copyright notice, and keywords) for SEO and tracking.
  17. Create a master ZIP file with all deliverables to prevent missing or corrupted files during transfer.
  18. Double-check file names for clarity (e.g., 'ClientName_ProjectName_Illustration_V1_Final.ai').
  19. Test print-ready files by sending a physical proof to yourself or a colleague before client delivery.
  20. Confirm the client has the necessary fonts installed or provide embedded font files (if licensed for distribution).
  21. Include any source files (sketches, brushes, textures) if the client paid for full ownership rights.
  22. Provide a brief project summary (1?2 sentences) outlining the concept and execution for client reference.
  23. Ask the client to sign off on final delivery via email or a project management tool to confirm receipt.
  24. Schedule a follow-up call or email within 48 hours to address any immediate questions or issues.
  25. Archive the project locally and in cloud storage for at least 1 year post-delivery for backup.
