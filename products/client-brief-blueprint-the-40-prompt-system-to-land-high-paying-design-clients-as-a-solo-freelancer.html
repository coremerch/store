Client Brief Blueprint: The 40-Prompt System to Land High-Paying Design Clients as a Solo Freelancer

client brief prompts for agency escapees going solo ? 40 prompts.

  1. List the top 3 pain points your ideal client faces that your design services solve.
  2. Describe the exact type of project your client needs (e.g., 'a minimalist logo redesign for a tech startup').
  3. Identify the client?s industry and provide 2-3 industry-specific design trends they might want to incorporate.
  4. State the client?s primary business goal for this project (e.g., 'increase brand recognition by 30%').
  5. Specify the client?s target audience demographics (age, location, interests).
  6. List 3 competitors the client admires and explain why.
  7. Detail the client?s budget range and payment terms they prefer.
  8. Identify the client?s preferred communication style (e.g., weekly updates, Slack, email).
  9. Provide the deadline and key milestones the client expects.
  10. List any existing brand assets the client wants to incorporate (colors, fonts, logos).
  11. Describe the client?s tone of voice (professional, playful, edgy) for all design communications.
  12. State whether the client needs a single deliverable (e.g., logo) or a full brand package (e.g., logo + style guide + social media templates).
  13. List any third-party integrations or platforms the design must be compatible with (e.g., Shopify, Adobe XD).
  14. Provide examples of 2-3 design styles the client likes and dislikes.
  15. State the client?s expectations for revisions (e.g., '2 rounds of revisions included').
  16. List any legal or trademark considerations the client needs addressed in the design.
  17. Identify the client?s preferred file formats for final deliverables (e.g., AI, PNG, PDF).
  18. State whether the client needs the design to be scalable for future use (e.g., responsive web design).
  19. List any specific colors or color palettes the client wants excluded from the design.
  20. Provide the client?s preferred typography style (e.g., sans-serif, serif, handwritten).
  21. State whether the client needs the design to align with a specific campaign or seasonal theme.
  22. List any technical requirements for the design (e.g., 'must load in under 2 seconds').
  23. Identify the client?s preferred delivery method (e.g., Dropbox, Google Drive, WeTransfer).
  24. State whether the client needs the design to be accessible (e.g., WCAG compliant).
  25. List any specific imagery or iconography styles the client wants to avoid.
  26. Provide the client?s preferred turnaround time for initial drafts and final delivery.
  27. State whether the client needs the design to be editable by them or their team (e.g., layered files).
  28. List any specific design elements the client wants to emphasize (e.g., 'must include a mascot').
  29. Identify the client?s preferred method for receiving feedback (e.g., annotated PDF, markup tool).
  30. State whether the client needs the design to be print-ready (e.g., CMYK color mode, 300 DPI).
  31. List any industry-specific guidelines the design must follow (e.g., FDA regulations for pharma).
  32. Provide the client?s preferred method for signing off on the final design (e.g., digital signature, email confirmation).
  33. State whether the client needs the design to be adaptable for different languages or regions.
  34. List any specific textures or patterns the client wants to include or exclude.
  35. Identify the client?s preferred method for presenting the design (e.g., in-person, video call, PDF).
  36. State whether the client needs the design to be optimized for social media sharing (e.g., square format for Instagram).
  37. List any specific symbols or motifs the client wants to incorporate or avoid.
  38. Provide the client?s preferred method for archiving past project files (e.g., organized folders, naming conventions).
  39. State whether the client needs the design to be future-proof (e.g., scalable vector files).
  40. List any specific design software the client prefers or requires for collaboration.
