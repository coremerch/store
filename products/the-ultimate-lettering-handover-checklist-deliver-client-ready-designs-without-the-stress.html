The Ultimate Lettering Handover Checklist: Deliver Client-Ready Designs Without the Stress

handover checklist for lettering artists ? 25 steps.

  1. Confirm project scope and deliverables with the client in writing before starting work.
  2. Provide a detailed contract outlining project milestones, revisions, and payment terms.
  3. Use a vector-based software (e.g., Adobe Illustrator, Procreate, Affinity Designer) for all lettering files.
  4. Ensure all lettering is outlined/stroked and not dependent on live type or plugins.
  5. Save the main lettering file as an editable vector file (e.g., .ai, .eps, .svg).
  6. Export a high-resolution PNG (300 DPI) of the final lettering with a transparent background.
  7. Create a flattened JPEG backup of the final design at 300 DPI for quick client previews.
  8. Provide an alternate color version of the lettering in CMYK for print-ready projects.
  9. Include a black-and-white version of the lettering for versatility in client materials.
  10. Deliver all lettering in the exact dimensions requested by the client (e.g., 8x10 inches).
  11. Provide a scalable vector file if the client plans to resize the lettering significantly.
  12. Include a style guide with font names, weights, and any custom adjustments made to the lettering.
  13. List all colors used in the design with Pantone, RGB, HEX, and CMYK values.
  14. Provide a breakdown of kerning, tracking, and leading adjustments applied to the lettering.
  15. Include a copy of the original sketch or rough drafts to show the evolution of the design.
  16. Deliver all alternate lettering concepts explored during the design process.
  17. Provide a PDF of the final lettering with embedded fonts and color profiles.
  18. Include a readme file with instructions on how to edit or modify the vector files if needed.
  19. Provide a mockup of the lettering in a real-world context (e.g., on a poster, business card, or mug).
  20. Deliver all social media-ready versions of the lettering (e.g., Instagram-optimized 1080x1080 pixels).
  21. Include a version of the lettering optimized for web use (e.g., SVG for scalability, optimized PNG for fast loading).
  22. Provide a license agreement outlining usage rights, attribution requirements, and commercial use permissions.
  23. Send an invoice for final payment with clear payment terms and due dates.
  24. Schedule a handover call or meeting to walk the client through the files and answer any questions.
  25. Follow up 48 hours after delivery to ensure the client has everything they need and is satisfied with the project.
