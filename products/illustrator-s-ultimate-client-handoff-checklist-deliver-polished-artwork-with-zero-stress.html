handover checklist for illustrators for hire ? 24 steps.

  1. Verify client?s preferred file format (PNG, JPG, PDF, SVG, etc.) and request confirmation in writing.

  3. Ensure color mode matches client?s needs (RGB for digital, CMYK for print).
  4. Check resolution is 300 DPI for print or 72 DPI for web/social media unless specified otherwise.
  5. Include a transparent background layer if the client intends to place the illustration over other elements.
  6. Provide a high-resolution version with a white background if the client requests it explicitly.
  7. Save a layered source file (AI, PSD, or EPS) only if the contract permits file sharing.
  8. Create a flattened version for clients who lack software to open layered files.
  9. Deliver a PDF portfolio-ready preview for easy client review or presentation.
  10. Include a README text file with project title, date, and your contact info for future reference.
  11. Label all files clearly: 'ProjectName_Illustration_Color_Web.jpg' or 'ProjectName_Final_SVG.ai'.
  12. Remove all unnecessary layers, hidden objects, and empty artboards from the source file.
  13. Check that all text layers have been converted to outlines or provided separately as a font file.
  14. Confirm all linked assets (images, brushes, patterns) are embedded or included in a ?Resources? folder.
  15. Provide a style guide snippet if the illustration includes custom typography or brand colors.
  16. Include alternate color variations if the project brief mentioned multiple color schemes.
  17. Deliver a low-resolution preview (300px on the longest side) for quick client approval before final delivery.
  18. Create a final folder structure: /Deliverables, /SourceFiles (if applicable), /Extras (sketches, references).
  19. Write a short usage note: 'Do not crop or alter artwork without permission to maintain proportions'.
  20. Include rights and licensing details in a separate ?License_Agreement.txt? file if usage terms were negotiated.
  21. Provide a one-paragraph artist?s statement about the creative process or inspiration (optional but valued).
  22. Conduct a final visual check for consistency in line weight, color balance, and overall composition.
  23. Test print the CMYK version on your end to confirm no unexpected shifts in color or detail.
  24. Send a follow-up email within 24 hours confirming delivery and offering minor revisions if needed.
