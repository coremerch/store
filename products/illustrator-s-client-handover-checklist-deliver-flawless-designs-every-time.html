Illustrator's Client Handover Checklist: Deliver Flawless Designs Every Time

handover checklist for illustrators for hire ? 25 steps.

  1. Verify all client-provided assets (references, briefs, brand guidelines) are saved in a dedicated project folder.
  2. Confirm project scope, deadlines, and deliverables (e.g., file formats, resolution, color modes) with the client in writing.
  3. Create a client-friendly folder structure (e.g., /ClientName/ProjectName/01_SourceFiles/02_Deliverables/) for easy navigation.
  4. Organize source files (AI, PSD, EPS, etc.) in a clearly labeled subfolder with version numbers (e.g., V1_Final_Approved).
  5. Export a high-resolution PNG/JPEG preview of the final illustration for quick client approval before final delivery.
  6. Provide a PDF proof with low-res previews of all variations (if applicable) for easy client review on any device.
  7. Label all deliverable files with the project name, date, and your signature/initials (e.g., ProjectName_20240515_Initials.ai).
  8. Include a ?Read Me? text file in the deliverables folder with step-by-step instructions for opening/editing files.
  9. Ensure all fonts used are either embedded in the file or provided as separate .TTF/.OTF files in a ?Fonts? subfolder.
  10. Gather all custom brushes, textures, or plugins used and save them in a ?Extras? subfolder with installation instructions.
  11. Convert all text to outlines (or provide editable text layers) and include a separate .DOCX with editable text for copy changes.
  12. Create a color swatch palette (ASE/ACO/PDF) matching the project?s brand guidelines for future reference.
  13. Bundle all linked assets (images, vectors) in a ?Assets? subfolder with original filenames for traceability.
  14. Provide a ?Project Recap? document summarizing the client?s original request, your solutions, and any revisions made.
  15. Include a license agreement (if applicable) outlining usage rights, attribution requirements, and commercial/personal use terms.
  16. Export a transparent PNG (PNG-24) for web use and a high-res JPEG for print-ready applications, if requested.
  17. Double-check all layers are properly labeled, grouped, and merged where necessary for client editing ease.
  18. Save a flattened TIFF/PSD version of the final illustration for archival purposes in a ?Archives? subfolder.
  19. Test all deliverable files on at least two devices (Mac/PC) to ensure compatibility and no missing links.
  20. Provide a short Loom video (3-5 min) walking the client through the file structure and how to use the assets.
  21. Include a ?Troubleshooting? guide with common issues (e.g., font replacement, missing assets) and fixes.
  22. Deliver a final invoice with clear payment terms, due date, and accepted payment methods (PayPal, Stripe, etc.).
  23. Send a follow-up email within 24 hours of delivery thanking the client and offering post-delivery support for 30 days.
  24. Archive the project in your personal records with a backup on an external drive/cloud storage for 1+ years.
  25. Request a testimonial or case study from the client within 1 week of project completion for future marketing.
