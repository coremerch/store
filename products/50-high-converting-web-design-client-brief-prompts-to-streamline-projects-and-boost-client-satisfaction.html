50 High-Converting Web Design Client Brief Prompts to Streamline Projects and Boost Client Satisfaction

client brief prompts for web designers ? 40 prompts.

  1. List the top 3 primary goals for the website (e.g., lead generation, brand awareness, e-commerce sales).
  2. Specify the target audience with detailed demographics (age, profession, interests, pain points).
  3. Define the key performance indicators (KPIs) the client wants to track after launch.
  4. Provide examples of 3-5 competitor websites the client admires for inspiration.
  5. Describe the tone and style the client wants to convey (e.g., modern, minimalist, playful, corporate).
  6. Outline the required pages (e.g., Home, About, Services, Blog, Contact) and their hierarchy.
  7. Detail the color palette preferences with hex codes or Pantone references.
  8. List 5-10 fonts the client wants to use or avoid (include font weights like light, regular, bold).
  9. Specify whether the website needs to be mobile-first, desktop-first, or fully responsive.
  10. Provide a sitemap outline including parent and child pages in a hierarchical format.
  11. List any existing branding elements (logo variations, brand guidelines, style guides).
  12. Include any third-party integrations required (e.g., CRM, payment gateways, email marketing tools).
  13. State the preferred content management system (CMS) (e.g., WordPress, Webflow, Squarespace).
  14. List the type of imagery the client prefers (e.g., illustrations, photography, abstract, 3D renders).
  15. Provide the client?s existing visual assets (e.g., high-res logo files, brand photography, icons).
  16. Specify the desired loading speed for the website (e.g., under 2 seconds, optimized for mobile).
  17. List any accessibility requirements (e.g., WCAG compliance, screen reader compatibility, color contrast ratios).
  18. State whether the client requires a blog or news section and its update frequency.
  19. Provide examples of 3-5 websites the client dislikes and explain why.
  20. Specify the budget range for the project (e.g., $3,000?$7,000, $10,000+).
  21. List the preferred project timeline with key milestones (e.g., design phase, development, testing, launch).
  22. State whether the client needs SEO optimization built into the design or a separate SEO strategy.
  23. Provide examples of 3-5 call-to-action (CTA) buttons the client wants to include.
  24. Specify the client?s preferred navigation style (e.g., hamburger menu, mega menu, sticky header).
  25. List any legal requirements (e.g., cookie consent, GDPR compliance, terms and conditions pages).
  26. Provide the client?s social media handles and how they want them integrated into the site.
  27. State whether the website needs a multilingual feature and specify the target languages.
  28. List any interactive elements required (e.g., animations, sliders, hover effects, chatbots).
  29. Specify the client?s preferred hosting provider and domain registrar.
  30. Provide examples of 3-5 micro-interactions the client wants (e.g., button hover effects, form validations).
  31. State whether the client needs a membership or subscription feature and outline its functionality.
  32. List any required forms (e.g., contact form, quote request, newsletter signup) and their fields.
  33. Specify the client?s preferred color for primary buttons and links (e.g., #FF5733 for call-to-action buttons).
  34. Provide the client?s existing analytics tools (e.g., Google Analytics, Hotjar) and access requirements.
  35. State whether the website needs a dark mode toggle and provide examples of preferred implementations.
  36. List any required video or audio elements (e.g., background videos, product demos, podcast embeds).
  37. Specify the client?s preferred method for collecting user feedback (e.g., surveys, contact forms, heatmaps).
  38. Provide examples of 3-5 loading animations or transitions the client likes.
  39. State whether the client needs a 404 error page design and provide examples of preferred styles.
  40. List any required API integrations (e.g., payment gateways, social media feeds, maps).
