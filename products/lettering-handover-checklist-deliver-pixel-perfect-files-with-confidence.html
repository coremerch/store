Lettering Handover Checklist: Deliver Pixel-Perfect Files with Confidence

handover checklist for lettering artists ? 25 steps.

  1. Verify contract terms and client approval for final deliverables
  2. Export final lettering artwork as a high-resolution PNG (300+ DPI)
  3. Export final lettering artwork as a lossless TIFF with transparency
  4. Provide layered AI/PSD file with editable paths and vector layers
  5. Include a flattened JPEG backup with client's preferred background color
  6. Organize all files in a dedicated folder labeled '[ProjectName]_Lettering_Final'
  7. Create a 'ReadMe.txt' file with project name, client name, and date
  8. List all fonts used with their licenses and download links
  9. Include a 'Fonts' subfolder with installed font files (if allowed by license)
  10. Provide color palette in HEX, RGB, and CMYK values
  11. Include a 'Color References' folder with swatches and gradients
  12. Deliver final lettering in SVG format for scalability and web use
  13. Provide a 'Style Guide' PDF with kerning pairs, spacing rules, and usage examples
  14. Include a 'Before & After' comparison image showing design evolution
  15. Provide a 'Versatility Preview' showing lettering in 3 different applications (e.g., mug, t-shirt, poster)
  16. Include a 'Do Not Use' list of colors, fonts, or styles to avoid
  17. Provide a 'Final Checklist' PDF confirming all deliverables are included
  18. Create a 'Usage Rights' document outlining licensing terms and restrictions
  19. Include a 'Contact Info' sheet with designer?s email and project timeline
  20. Provide a 'File Naming Convention' guide for easy organization
  21. Include a 'Troubleshooting Guide' for common issues (e.g., font substitution, color shifts)
  22. Deliver a 'Web-Ready' version optimized for social media (e.g., Instagram-friendly dimensions)
  23. Include a 'Print-Ready' version with 3mm bleed and cut marks
  24. Provide a 'Hand-Lettering Sketch' folder with original pencil/ink scans (if applicable)
  25. Include a 'Client Feedback Summary' PDF documenting final adjustments and approvals
