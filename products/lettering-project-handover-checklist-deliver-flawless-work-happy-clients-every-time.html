Lettering Project Handover Checklist: Deliver Flawless Work + Happy Clients Every Time

handover checklist for lettering artists ? 25 steps.

  1. Verify client?s final lettering brief (style, mood, key words, and any reference images) before starting work
  2. Collect all provided reference materials (fonts, sketches, mood boards) in a single folder
  3. Confirm project scope: deliverables list (e.g., vector files, raster exports, social templates), quantity, and sizes
  4. Ask client for preferred file formats (AI, SVG, PNG, etc.) and color modes (RGB/CMYK) upfront
  5. Set up a project folder structure with subfolders labeled: Assets, Drafts, Finals, Exports, and Correspondence
  6. Create a naming convention for files (e.g., ClientName_ProjectType_Date_Version) and share it with the client for transparency
  7. Design a style guide slide with font names, weights, color codes, spacing, and sample lettering phrases
  8. Include a short usage guide: minimum size for legibility, best backgrounds, and sizing recommendations
  9. Ensure all vector paths are closed, nodes are clean, and no stray points exist in the lettering
  10. Check that anchor points are smooth and curves are consistent?no awkward bumps or kinks in strokes
  11. Confirm all text layers are expanded or outlined and font licenses are either purchased or properly credited
  12. Test lettering at actual size (e.g., 1080px wide for social media) to ensure clarity and proportions
  13. Export a high-resolution PNG (300 DPI) of the final lettering with transparent background for quick previews
  14. Provide a low-res JPEG (72 DPI, 1000px wide) optimized for web and email sharing
  15. Create a vector-only SVG file for future scalability and client use in design software
  16. Bundle all deliverables into a single ZIP file with a clear folder structure and a readme.txt
  17. Include a short video walkthrough (Loom or mp4) showing how to use the files and access the style guide
  18. Add a contact sheet with your name, email, website, and social handles in the ZIP file
  19. Include a short invoice or receipt with project details, hours, and payment confirmation
  20. Send a final email summarizing what?s included, next steps, and how to reach you for revisions or questions
  21. Set up a follow-up reminder for 3?5 days later to check if the client needs help implementing the lettering
  22. Prepare a list of common FAQs (e.g., "Can I print this at 4K?", "Can I use this in a logo?") with answers
  23. Ask for a testimonial or case study prompt in your follow-up, making it easy for the client to say yes
  24. Archive the project in your portfolio or client tracker with a tag for repeat business and referrals
  25. Send a thank-you message with a discount code for future projects to encourage repeat clients
