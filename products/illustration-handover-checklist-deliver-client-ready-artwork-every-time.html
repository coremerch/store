Illustration Handover Checklist: Deliver Client-Ready Artwork Every Time

handover checklist for illustrators for hire ? 24 steps.

  1. Confirm final project scope and deliverables with the client in writing
  2. Verify project timeline, milestones, and final deadline with the client
  3. Gather and organize all client-provided reference materials (sketches, mood boards, brand guidelines)
  4. Create a dedicated project folder structure on your device (e.g., /ClientName/ProjectName/)
  5. Set up a shared cloud folder (Google Drive, Dropbox, etc.) for client uploads and feedback
  6. Label all files with a consistent naming convention (e.g., ClientName_ProjectName_VersionDate.ext)
  7. Export initial rough sketches or thumbnails for client approval before finalizing
  8. Create a color palette document (RGB, CMYK, and HEX values) for client sign-off
  9. Develop a style guide outlining line weights, shapes, and any recurring design elements
  10. Save all original vector files in editable formats (AI, EPS, SVG) with organized layers
  11. Export high-resolution raster files (PNG, JPEG) at 300 DPI for print use
  12. Provide web-optimized versions (PNG, JPEG) at 72 DPI and smaller file sizes
  13. Include alternate file formats (PDF, SVG) if requested by the client
  14. Create a final artboard with all approved illustrations in one file for easy review
  15. Add a transparent background version of each illustration (PNG) for versatility
  16. Document any custom brushes, textures, or effects used in the illustrations
  17. Include a README file with instructions for opening, editing, and using the files
  18. List all font names and sources used in the illustrations (if applicable)
  19. Provide a contact sheet or gallery of all final illustrations for client reference
  20. Export an animated version (GIF, MP4) if the project includes motion graphics
  21. Prepare a usage rights document outlining licensing terms and restrictions
  22. Include a client feedback form template for future project iterations
  23. Schedule a handover meeting to walk the client through the delivered files
  24. Send a follow-up email summarizing deliverables, next steps, and contact information
