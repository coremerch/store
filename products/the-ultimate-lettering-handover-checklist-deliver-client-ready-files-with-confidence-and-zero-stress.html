The Ultimate Lettering Handover Checklist: Deliver Client-Ready Files with Confidence and Zero Stress

handover checklist for lettering artists ? 24 steps.

  1. Verify all lettering artwork is finalized and approved by the client before proceeding.
  2. Export each lettering piece as a high-resolution PNG (300 DPI minimum, transparent background).
  3. Save the lettering as a vector file (AI, EPS, or SVG format) with all paths outlined and editable.
  4. Include a layered PSD file if the lettering was created in Photoshop, with separate layers for each element.
  5. Provide a PDF proof with the lettering locked in place for client review and final approval.
  6. Check that all custom letterforms are scalable without pixelation or distortion.
  7. Ensure all ligatures, swashes, and alternate glyphs are included in the final files.
  8. Create a style guide (1-page PDF) outlining font usage, color codes (CMYK, RGB, Pantone), and spacing rules.
  9. Include a separate file for any custom brushes or textures used in the lettering process.
  10. Save a flattened JPEG version for quick client previews or social media use.
  11. Organize all files in a dedicated folder named 'Lettering_Final_Delivery_[ProjectName]_[Date]'.
  12. Label each file clearly with the project name, date, and version number (e.g., 'ProjectX_Lettering_Final_v1.ai').
  13. Provide a readme.txt file with instructions on how to access and use the files.
  14. Confirm all client contact information is accurate and up-to-date before delivery.
  15. Send a follow-up email with a download link to the files and a thanks-for-working-with-us note.
  16. Include a breakdown of all deliverables (e.g., '3 main lettering designs, 2 alternate versions, 1 style guide').
  17. Test all files on different devices and software to ensure compatibility and accessibility.
  18. Offer a 15-minute call or screen share to walk the client through the files if needed.
  19. Provide any additional assets like mockups (e.g., lettering on a t-shirt, poster, or sign).
  20. Ensure all color profiles (sRGB, Adobe RGB) are embedded in exported files for accurate color reproduction.
  21. Remove any unused layers, hidden elements, or client work from the final files to avoid confusion.
  22. Include a contact sheet with small previews of all lettering variations for easy reference.
  23. Add a section in the style guide for any special usage rules (e.g., minimum size, clear space requirements).
  24. Archive a backup copy of all files on a cloud service or external drive for your records.
