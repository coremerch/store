Lettering Project Handover Blueprint: Deliver Client-Ready Files Every Time

handover checklist for lettering artists ? 25 steps.

  1. Provide a high-resolution scan or photograph of the finished lettering artwork at 300 DPI or higher
  2. Include a layered Photoshop file (.psd) with all lettering elements separated on individual layers
  3. Export a transparent PNG of the lettering for easy placement over any background
  4. Create a vector version of the lettering in Adobe Illustrator (.ai) or SVG format
  5. Ensure all vector paths are closed and free of stray anchor points for scalability
  6. Organize the Illustrator file with grouped lettering elements and labeled layers
  7. Include a color swatch palette in both RGB and CMYK values for consistency
  8. Provide a PDF proof of the lettering layout at 100% size for client approval
  9. Export the lettering as a transparent PNG sequence if animation is part of the deliverable
  10. Include a readme.txt file with font names, sizes, and spacing details used in the design
  11. Provide a style guide documenting lettering stroke weights, serif styles, and baseline alignment
  12. Export a flattened JPEG of the final artwork for quick client review if requested
  13. Include any custom brushes or textures used in the lettering process as separate files
  14. Provide a version of the lettering with white fill on a transparent background for use on dark backgrounds
  15. Create a version of the lettering with black fill on a transparent background for versatility
  16. Include a version of the lettering with a subtle drop shadow for depth if applicable
  17. Provide a version of the lettering with a background color matching the final application
  18. Export the lettering in grayscale for monochrome use cases (e.g., engraving or etching)
  19. Include a version of the lettering optimized for social media (e.g., Instagram-ready dimensions)
  20. Provide a version of the lettering with reversed text (mirrored) for engraving or stamping
  21. Include a version of the lettering with all caps, lowercase, and title case options if applicable
  22. Provide a version of the lettering with alternate character ligatures or swashes if designed
  23. Include a version of the lettering with kerning adjustments applied for final readability
  24. Provide instructions for resizing the lettering without loss of quality or distortion
  25. Include a contact sheet showing the lettering in various applications or mockups for inspiration
