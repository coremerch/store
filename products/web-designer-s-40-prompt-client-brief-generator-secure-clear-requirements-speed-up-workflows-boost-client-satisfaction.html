Web Designer?s 40-Prompt Client Brief Generator: Secure Clear Requirements, Speed Up Workflows & Boost Client Satisfaction

client brief prompts for web designers ? 40 prompts.

  1. List the primary goal of the website (e.g., lead generation, e-commerce sales, brand awareness) with measurable KPIs like conversion rate or revenue targets.
  2. Identify the target audience personas including demographics (age, gender, income), psychographics (values, pain points), and user behaviors (devices used, browsing habits).
  3. Request a sitemap draft or navigation structure from the client to understand their preferred hierarchy and key pages (Home, About, Services, Contact, etc.).
  4. Ask for a list of 3-5 direct competitors for visual and functional inspiration, including specific URLs and key features they admire.
  5. Specify the number of pages or sections needed and whether they require templates for future scalability (e.g., blog, product pages, FAQs).
  6. Gather the client?s preferred color palette including primary, secondary, and accent colors with HEX codes for consistency.
  7. Obtain 3-5 examples of websites they like in terms of style (minimalist, bold, playful, corporate) and explain why each example resonates with them.
  8. Clarify the desired tone of voice for the website content (professional, friendly, humorous, authoritative) and provide examples of copy they prefer.
  9. Request the client?s logo files in multiple formats (PNG, SVG, EPS) and usage guidelines (minimum size, color variations, transparent background requirements).
  10. Ask for a list of 3-5 must-have features (e.g., contact forms, live chat, booking system, newsletter signup) and their priority ranking.
  11. Provide a detailed description of the client?s brand personality (e.g., innovative, trustworthy, luxurious) and how it should be reflected in the design.
  12. Specify if the website needs to be mobile-responsive and if there are any mobile-specific design considerations (e.g., touch targets, load speed).
  13. Request a list of any third-party integrations needed (e.g., CRM, payment gateways, social media feeds) including API requirements or plugin preferences.
  14. Ask for examples of any existing marketing materials (brochures, business cards, social media posts) to maintain visual consistency across the website.
  15. Clarify the client?s preferred typography, including font families for headings, body text, and any special elements (buttons, quotes) with Google Fonts links if applicable.
  16. Request a list of any legal or compliance requirements (e.g., GDPR, accessibility standards, industry regulations) that must be incorporated into the design.
  17. Ask for a timeline with key milestones (e.g., initial design drafts, revisions, final delivery, launch date) and any external dependencies (e.g., content approval, third-party launch processes).
  18. Specify the budget range and any constraints (e.g., premium plugins, custom illustrations, stock photography budget) to align expectations.
  19. Request a list of any existing content (text, images, videos) the client wants to repurpose and its current format (Word docs, PDFs, high-res images).
  20. Ask for the client?s preferred layout grid system (e.g., 12-column grid, asymmetrical) and spacing guidelines (e.g., 8px, 16px, 24px).
  21. Identify if the website needs multilingual support and specify the languages required, including any cultural or regional design considerations.
  22. Request examples of any animations or micro-interactions the client wants to include (e.g., hover effects, loading animations, parallax scrolling).
  23. Ask for the client?s preferred image style (e.g., realistic, illustrated, abstract) and whether they have a library of images or need sourcing recommendations.
  24. Specify if the website needs a content management system (CMS) preference (e.g., WordPress, Webflow, Shopify) and their technical comfort level for managing updates.
  25. Request a list of any SEO requirements including target keywords, meta descriptions, image alt text, and on-page optimization expectations.
  26. Ask for the client?s preferred loading speed expectations and any specific performance benchmarks (e.g., under 2 seconds, Google PageSpeed score above 90).
  27. Specify if the website needs to support e-commerce functionality including product categories, payment methods, and shipping calculator preferences.
  28. Request examples of any social proof elements the client wants to include (e.g., client logos, testimonials, case studies, trust badges).
  29. Ask for the client?s preferred call-to-action (CTA) placements (e.g., above the fold, after every section, sidebar) and design preferences (color, shape, size).
  30. Identify if the website needs to include a blog or news section and specify its purpose (e.g., thought leadership, SEO, updates) and frequency of posts.
  31. Request the client?s preferred approach to accessibility (e.g., WCAG 2.1 AA compliance, screen reader testing, color contrast ratios) and any specific tools they prefer (e.g., axe, WAVE).
  32. Ask for the client?s preferred approach to user testing including methods (e.g., A/B testing, heatmaps, user surveys) and who will conduct the tests.
  33. Specify if the website needs to include a membership or login area and outline the user roles, permissions, and password policies.
  34. Request examples of any interactive elements the client wants to include (e.g., calculators, quizzes, maps, sliders) and their purpose.
  35. Ask for the client?s preferred approach to analytics and tracking including tools (e.g., Google Analytics, Hotjar) and key metrics to monitor.
  36. Identify if the website needs to integrate with a customer relationship management (CRM) system and specify the required fields and automation workflows.
  37. Request the client?s preferred approach to hosting including budget range, preferred providers (e.g., AWS, SiteGround, Vercel), and any security requirements (SSL, backups).
  38. Ask for the client?s preferred approach to maintenance and updates including frequency (monthly, quarterly) and who will handle them (client, agency, freelancer).
  39. Specify if the website needs to include a live chat or chatbot feature and outline its purpose (e.g., customer support, sales assistance) and preferred platform (e.g., Intercom, Drift).
  40. Request the client?s preferred approach to email marketing integration including preferred ESP (e.g., Mailchimp, HubSpot) and list segmentation strategies.
