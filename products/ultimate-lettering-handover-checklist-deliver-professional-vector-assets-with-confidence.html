Ultimate Lettering Handover Checklist: Deliver Professional Vector Assets with Confidence

handover checklist for lettering artists ? 25 steps.

  1. Verify all lettering paths are closed and free of gaps using Pathfinder or equivalent tool
  2. Confirm no overlapping anchor points exist within any letterforms
  3. Ensure all curves are smooth with no kinks by checking B?zier handles visually
  4. Convert all text to outlines (Create Outlines) to prevent font dependency issues
  5. Delete any hidden layers or stray objects not part of final composition
  6. Check and correct any misaligned baselines or inconsistent optical sizing
  7. Set precise kerning between all adjacent characters using numeric values
  8. Standardize stroke weights across all letters for visual consistency
  9. Export a high-resolution PNG preview at 300 DPI for client approval
  10. Generate a print-ready PDF with outlined text and embedded images (if applicable)
  11. Provide layered AI/PSD files with named groups for each word or phrase
  12. Include a style guide summary in a separate text file (e.g., stroke width, spacing ratios)
  13. Deliver a clean SVG version optimized for web use with minimal anchor points
  14. Create a font specimen sheet showing each character in a grid layout
  15. Add a credits file listing all fonts, tools, and resources used in creation
  16. Include a README with step-by-step setup instructions for clients or printers
  17. Test all deliverables on both Mac and Windows systems for compatibility
  18. Check color mode consistency (CMYK for print, RGB for digital; no mixed modes)
  19. Verify all linked images are embedded or provided as separate high-res files
  20. Include a non-disclosure agreement (NDA) template if handling proprietary designs
  21. Provide a version history log tracking changes and client feedback iterations
  22. Add a contact sheet with your branding, website, and availability for revisions
  23. Ensure all files are named clearly (e.g., ClientName_Project_Lettering_V01.ai)
  24. Include a license agreement specifying usage rights and commercial terms
  25. Conduct a final quality control pass for spelling errors and visual harmony
