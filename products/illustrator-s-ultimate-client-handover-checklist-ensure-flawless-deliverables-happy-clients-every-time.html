Illustrator's Ultimate Client Handover Checklist: Ensure Flawless Deliverables & Happy Clients Every Time

handover checklist for illustrators for hire ? 25 steps.

  1. Verify client's preferred file formats (AI, EPS, PNG, JPEG, SVG, PDF) before starting work.
  2. Confirm deliverable resolution (300 DPI for print, 72 DPI for web) with the client.
  3. Create a backup folder with project name and date (e.g., '2024-05-15_ClientName_ProjectName_Backup').
  4. Save all source files (AI, PSD, etc.) in a dedicated 'SourceFiles' subfolder.
  5. Organize deliverables into a 'FinalDeliverables' subfolder with clearly labeled files.
  6. Include a 'ReadMe_First.txt' file in the root folder with project name, client name, and contact info.
  7. Provide a client-ready summary document (PDF) listing all deliverables and their uses.
  8. Double-check file names for clarity (e.g., 'ClientName_Illustration_Vector.ai' vs. 'Untitled-1.ai').
  9. Ensure all vector files have proper artboard alignment and no stray points or anchors.
  10. Flatten transparent elements where necessary to avoid compatibility issues in older software.
  11. Export raster files at the exact dimensions specified by the client (e.g., 1024x768px).
  12. Include a 'ColorSwatches' folder with Pantone, CMYK, and RGB color values if color accuracy is critical.
  13. Provide a 'FontsUsed' document listing all fonts (names and licenses) if custom fonts were used.
  14. Create a 'StyleGuide' PDF with typography, color palettes, and spacing rules for consistency.
  15. Include a 'UsageRights' document outlining permitted uses (e.g., commercial, editorial, personal).
  16. Provide a 'RevisionHistory' log tracking changes, dates, and versions for transparency.
  17. Verify that all linked assets (images, brushes) are embedded or included in a 'Resources' folder.
  18. Run a spell-check on all text elements in the final files, even if proofed earlier.
  19. Check for and correct any spelling errors in file names or folder structures.
  20. Test all exported files (PNG, JPEG) for visual consistency across devices and software.
  21. Ensure all deliverables are free of proprietary software artifacts (e.g., Illustrator?s hidden guides).
  22. Include a 'QuickStartGuide' (1-page PDF) with basic instructions for using the files.
  23. Provide a 'ContactInfo' card with your name, email, and portfolio link for future reference.
  24. Zip the entire project folder and verify the archive opens correctly on multiple devices.
  25. Schedule a follow-up call or email to confirm the client received and understood the deliverables.
