The Ultimate Lettering Handover Checklist: Client-Ready Deliverables Every Time

handover checklist for lettering artists ? 25 steps.

  1. Verify all client-provided references (fonts, sketches, or style guides) are included in the project folder.
  2. Organize project files in a clear directory structure: /01_Source_Files, /02_Final_Assets, /03_Documentation.
  3. Export all lettering variations (uppercase, lowercase, numerals, punctuation) as individual SVG files with proper naming (e.g., 'SVG_A.svg', 'SVG_a.svg').
  4. Provide a master AI/PDF file with layered lettering for easy edits, including hidden layers for guides and references.
  5. Save a high-resolution PNG (300 DPI) of the final lettering in both light and dark backgrounds for quick previews.
  6. Create a separate PDF with only the lettering (no background) for mockup purposes, optimized for 300 DPI.
  7. Include a color palette document (AI/PDF) with Pantone, RGB, HEX, and CMYK values for all used colors.
  8. Provide a typography sheet (AI/PDF) showing kerning, tracking, and any custom adjustments made to spacing.
  9. Export the lettering as a transparent PNG sequence for animated or interactive projects.
  10. Deliver a style guide (PDF) outlining minimum size requirements, spacing rules, and usage do?s and don?ts.
  11. Include a 'How to Use' PDF with step-by-step instructions for applying the lettering in common design software (Illustrator, Photoshop, Procreate).
  12. Provide vector files in .AI and .EPS formats with all paths outlined and fonts converted to outlines.
  13. Export a web-optimized PNG (72 DPI) for digital use, with transparent background and optimized file size.
  14. Include a batch of social media-ready assets (1080x1080, 1080x1350, 4K) with the lettering applied to mockup templates.
  15. Deliver a 3D mockup set (PSD) with the lettering applied to at least 5 different physical surfaces (wood, metal, fabric, etc.).
  16. Provide a 'Before & After' comparison image showing the lettering applied to a client-provided template.
  17. Include a font usage license agreement (PDF) outlining terms for commercial and personal use.
  18. Export a separate file for each language variant if multilingual lettering was created (e.g., 'Lettering_EN.ai', 'Lettering_ES.ai').
  19. Provide a 'Quick Start' guide (PDF) with the top 5 most common use cases for the lettering (e.g., business cards, social media, banners).
  20. Include a 'Troubleshooting' document (PDF) addressing common issues like scaling, alignment, or color shifts.
  21. Deliver a final invoice and payment receipt in a branded PDF with project details, dates, and payment terms.
  22. Provide a 'Thank You' email template (HTML/Plain Text) for the client to use when sharing the project on social media or with colleagues.
  23. Include a video tutorial (MP4) showing how to install and use the lettering in Adobe Illustrator or Procreate (5-10 minutes max).
  24. Export a press-ready PDF (300 DPI, CMYK) for print publications, with bleed and crop marks included.
  25. Provide a 'Future Updates' document (PDF) outlining how the client can request revisions or additional formats in the future.
