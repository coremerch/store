Web Design Client Briefs: 40 Ready-to-Use Prompts for Faster, Higher-Value Projects

client brief prompts for web designers ? 40 prompts.

  1. Ask the client to provide 3-5 websites they admire and explain why in detail.
  2. Request the client?s brand style guide (colors, fonts, logo usage) or ask them to create one before starting.
  3. Ask for the target audience demographics (age, location, profession) with supporting data if possible.
  4. Request a list of 3-5 competitor websites and ask the client to highlight what they like or dislike about each.
  5. Ask the client to share their primary business goal for the website (e.g., lead generation, sales, brand awareness).
  6. Request a sitemap draft from the client, including all pages and subpages they want included.
  7. Ask for the client?s preferred tone of voice (e.g., professional, friendly, humorous) for all written content.
  8. Request the client?s top 3-5 keywords for SEO and their preferred keyword placement strategy.
  9. Ask if the client has any existing marketing materials (brochures, social media posts) that should align with the website design.
  10. Request a list of 3-5 must-have features (e.g., contact forms, booking system, e-commerce) the website must include.
  11. Ask the client to provide examples of websites they dislike and explain why in detail.
  12. Request the client?s preferred layout style (e.g., minimalist, modern, playful) and provide 2-3 visual references.
  13. Ask for the client?s budget range and timeline for the project to ensure alignment before starting.
  14. Request the client?s social media profiles to ensure branding consistency across platforms.
  15. Ask if the client has any existing brand assets (photos, videos, illustrations) they want to use on the website.
  16. Request a list of 3-5 industry trends the client wants the website to reflect (e.g., dark mode, micro-interactions).
  17. Ask the client to identify their top 3 competitors and describe their unique selling points.
  18. Request the client?s mobile optimization requirements (e.g., responsive design, mobile-first approach).
  19. Ask if the client has any accessibility requirements (e.g., WCAG compliance, screen reader support).
  20. Request the client?s preferred navigation structure (e.g., mega menus, hamburger menus, sidebar navigation).
  21. Ask for examples of websites with navigation styles the client prefers or dislikes.
  22. Request the client?s preferred color palette and any colors they want to avoid due to brand guidelines.
  23. Ask if the client has any specific font preferences or branding guidelines for typography.
  24. Request the client?s logo files in multiple formats (vector, PNG, SVG) for seamless integration.
  25. Ask for the client?s preferred imagery style (e.g., illustrations, photos, abstract graphics) and provide examples.
  26. Request the client?s preferred call-to-action (CTA) button styles (e.g., color, shape, size, placement).
  27. Ask if the client wants to include a blog or news section and, if so, request a content strategy outline.
  28. Request the client?s preferred loading speed expectations and any performance benchmarks they aim for.
  29. Ask for the client?s preferred hosting provider and technical requirements (e.g., CMS, server specifications).
  30. Request the client?s preferred domain name and any existing domain details for transfer or integration.
  31. Ask if the client wants to integrate third-party tools (e.g., CRM, analytics, payment gateways) and provide examples.
  32. Request the client?s preferred email marketing strategy and if they want newsletter sign-up forms on the site.
  33. Ask for the client?s preferred social media integration strategy (e.g., feed embedding, sharing buttons).
  34. Request the client?s preferred legal page requirements (e.g., privacy policy, terms of service, cookie consent).
  35. Ask if the client has any existing customer testimonials or case studies they want to feature on the website.
  36. Request the client?s preferred contact form structure (e.g., fields, layout, confirmation messages).
  37. Ask for the client?s preferred team or staff page design (e.g., bios, photos, social links).
  38. Request the client?s preferred product or service page layout (e.g., grid, list, masonry).
  39. Ask if the client wants to include a FAQ section and, if so, request a draft of common questions and answers.
  40. Ask for the client?s preferred error page design (e.g., 404 page, maintenance mode page).
