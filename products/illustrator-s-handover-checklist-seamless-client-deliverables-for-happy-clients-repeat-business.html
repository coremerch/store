Illustrator's Handover Checklist: Seamless Client Deliverables for Happy Clients & Repeat Business

handover checklist for illustrators for hire ? 25 steps.

  1. Verify client?s preferred file formats (e.g., PNG, SVG, PDF, AI, or EPS).
  2. Confirm color mode (RGB for digital, CMYK for print) matches project needs.
  3. Check resolution is 300 DPI for print or 72/96 DPI for web unless specified otherwise.
  4. Provide layered source files (e.g., .ai, .psd, .eps) with all editable elements.
  5. Organize layers with clear, descriptive names (e.g., 'background', 'character_shadow').
  6. Flatten unnecessary layers for final deliverables unless client requests editable layers.
  7. Include a style guide (color palette, typography, spacing rules) if applicable.
  8. Export transparent PNGs with no white matte or unwanted background edges.
  9. Create vector exports (SVG or EPS) with clean paths and no stray anchor points.
  10. Provide high-res proof for client approval before final delivery (e.g., PDF or JPG).
  11. Ensure all text is converted to outlines or provided in a separate editable file.
  12. Deliver a version optimized for web (smaller file size, responsive dimensions).
  13. Provide a version optimized for print (bleed, crop marks, and correct color profile).
  14. Include any custom brushes or patterns used, with instructions for client installation.
  15. Provide a README file with file naming conventions and folder structure explanation.
  16. Deliver a final invoice with payment confirmation and project completion notes.
  17. Send a thank-you email with usage rights summary and next steps for revisions.
  18. Offer a 30-day post-delivery revision window for minor tweaks (if applicable).
  19. Include contact info for technical support or questions about delivered files.
  20. Provide a link to download all files via a cloud service (Google Drive, Dropbox, etc.).
  21. Confirm client has received and can open all files without compatibility issues.
  22. Archive project files with a unique project code for future reference (e.g., 'CLIENT_2024_PROJ01').
  23. Include a changelog or version history in the README for any updates made.
  24. Offer to provide source files in an older software version if client requests it.
  25. Schedule a quick follow-up call or email to ensure client satisfaction and gather testimonial feedback.
