Ultimate Lettering Artist's Project Handover Checklist: Deliver Flawless Designs Every Time

handover checklist for lettering artists ? 24 steps.

  1. Confirm client?s preferred file formats (AI, EPS, SVG, PNG, PDF) and deliver them all in a single compressed folder.
  2. Organize files with clear naming conventions (e.g., ProjectName_Type_Date_Initials.ai).
  3. Include a master layered file with all lettering elements intact and properly grouped.
  4. Provide a flattened high-resolution PNG/JPEG for quick client previews.
  5. Export a transparent PNG of each individual letter or word for easy social media sharing.
  6. Embed all fonts used in the project into the files or convert text to outlines.
  7. Create a separate color swatch file with Pantone, RGB, CMYK, and HEX values for all used colors.
  8. Include a style guide document detailing font names, sizes, spacing (tracking, kerning), and baseline alignment rules.
  9. Provide a vector-based background file if a custom backdrop was designed (e.g., grunge, watercolor, geometric).
  10. Deliver a PDF proof with all variations (uppercase, lowercase, alternate characters) for client reference.
  11. Include a read-only version of the master file for client archiving (e.g., PDF or locked AI file).
  12. Add a 'Read Me' text file with step-by-step instructions for opening, editing, and using the files correctly.
  13. Provide mockup images showing the lettering applied to client?s intended surfaces (e.g., t-shirts, signage, packaging).
  14. Include a list of recommended printing services or materials if the design is meant for physical production.
  15. Provide source files for any custom brushes, textures, or effects used in the lettering (e.g., Procreate brushes, Photoshop actions).
  16. Create a timeline or version history document listing key design changes and their dates for client transparency.
  17. Include contact information for font licenses or stock assets used to avoid legal complications.
  18. Provide a brief but clear copyright notice in the 'Read Me' file outlining usage rights and restrictions.
  19. Deliver a final invoice with a detailed breakdown of all deliverables, revisions, and associated costs.
  20. Include a feedback form template for clients to submit specific comments on each element of the design.
  21. Provide a list of alternative colorways or variations for future use or branding flexibility.
  22. Add a 'Quick Start' guide with the three most important files to open first for non-designers.
  23. Include a link to a cloud folder (Google Drive, Dropbox) with all files organized by category for easy access.
  24. Provide a short video tutorial (5-10 minutes) demonstrating how to edit and manipulate the lettering files in Adobe Illustrator.
