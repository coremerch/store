Web Design Client Brief Generator: 40 High-Converting Prompts to Land More Projects & Delight Clients

client brief prompts for web designers ? 40 prompts.

  1. What is the primary goal of the website? (e.g., sell products, generate leads, showcase portfolio, inform visitors)
  2. Who is the ideal target audience for this website? List demographics (age, gender, location) and psychographics (interests, pain points).
  3. What are the top 3 competitors? websites you admire? Provide URLs and explain what features or design elements attract you.
  4. What are 2-3 specific websites (not competitors) that inspire the desired aesthetic or functionality? Share URLs and highlight key elements.
  5. What is the preferred color palette for the website? Provide hex codes or describe mood (e.g., modern, vintage, minimalist).
  6. What is the main navigation structure? List primary menu items and any sub-menus or dropdowns needed.
  7. Should the website include a blog, news section, or dynamic content feeds? If yes, describe the purpose and frequency of updates.
  8. What type of hero section do you envision? (e.g., full-screen video, slider with call-to-action buttons, static image with overlay text)
  9. Are there any specific animations or micro-interactions you?d like to include? Describe where and how they should appear.
  10. What is the preferred typography style? Provide font names (e.g., Open Sans for body, Playfair Display for headings) or describe the mood (e.g., elegant, bold, clean).
  11. Should the website be mobile-first, desktop-first, or fully responsive? Describe any specific breakpoints for mobile/tablet views.
  12. What is the desired loading speed benchmark? (e.g., under 2 seconds, optimized for 3G networks)
  13. Are there any accessibility requirements? (e.g., WCAG compliance, screen reader compatibility, high contrast mode)
  14. What forms will the website include? List all forms (e.g., contact, newsletter signup, checkout) and required fields.
  15. Should the website include e-commerce functionality? If yes, list payment gateways, product types, and shipping options.
  16. What is the preferred layout for product/service pages? (e.g., grid, list, single-column with large images)
  17. Are there any third-party integrations required? (e.g., CRM, email marketing tools, social media feeds, analytics)
  18. What is the tone of voice for the website copy? (e.g., professional, casual, humorous, authoritative)
  19. Provide 3-5 key messages or value propositions to highlight prominently on the homepage.
  20. What is the budget range for this project? (e.g., $1,000?$3,000, $5,000?$10,000)
  21. What is the project timeline? List key milestones (e.g., discovery on Feb 1, design mockups by Feb 15, development complete by March 1).
  22. Who will be the primary point of contact for feedback and approvals? Provide name, email, and preferred communication method.
  23. How will success be measured? (e.g., conversion rate, bounce rate, time on page, number of leads generated)
  24. Are there any existing brand assets to use? (e.g., logo files, brand style guide, high-res images, pre-written copy)
  25. What is the desired hosting solution? (e.g., shared hosting, VPS, managed WordPress hosting, custom server)
  26. Should the website include a search functionality? If yes, describe the expected scope (e.g., simple search bar, advanced filters).
  27. What is the preferred content management system (CMS)? (e.g., WordPress, Webflow, Squarespace, custom-built)
  28. Are there any legal or compliance requirements? (e.g., GDPR, cookie consent, terms of service, privacy policy)
  29. What is the preferred method for delivering design mockups? (e.g., Figma, Adobe XD, Sketch, PDF, live prototype)
  30. Should the website include a membership or login area? If yes, describe user roles and permissions.
  31. What is the preferred method for handling user feedback during the design process? (e.g., in-app comments, email threads, scheduled calls)
  32. Are there any specific security requirements? (e.g., SSL certificate, firewall protection, regular backups)
  33. What is the preferred method for handing off the final website? (e.g., GitHub repository, one-click installer, manual transfer)
  34. Should the website include a live chat or customer support integration? If yes, describe the expected features.
  35. What is the preferred method for tracking user behavior? (e.g., Google Analytics, Hotjar, custom event tracking)
  36. Are there any social media profiles or external links that need to be prominently featured?
  37. What is the preferred method for handling future updates and maintenance? (e.g., retainer, one-time fee, DIY with provided documentation)
  38. Are there any specific animations or transitions you?d like to avoid? (e.g., parallax scrolling, auto-play videos)
  39. What is the preferred method for displaying testimonials or client logos? (e.g., carousel, grid, ticker)
  40. Should the website include a FAQ section? If yes, provide sample questions or topics to cover.
