Ultimate Client Handoff Checklist for Illustrators: 25 Steps to Flawless Deliverables & Happy Clients

handover checklist for illustrators for hire ? 24 steps.

  1. Verify client?s preferred file format (PNG, JPEG, SVG, AI, PDF, etc.) before starting work.
  2. Confirm final dimensions for all deliverables (e.g., 1920x1080 for social media, 300 DPI for print).
  3. Set up a shared folder in Google Drive, Dropbox, or WeTransfer for easy file transfer.
  4. Create a naming convention for files (e.g., ProjectName_IllustrationType_Version_Date).
  5. Add a watermark or low-res preview to protect unpublished work during revisions.
  6. Export all illustrations at the correct resolution and file size for client?s intended use.
  7. Include a vector file (AI or EPS) for scalability, even if client only requested raster files.
  8. Provide separate layers for editable elements (e.g., background, character, text) in the source file.
  9. Offer a layered PSD file if the client may need to adjust colors or elements later.
  10. Include a color palette or swatch file in ASE or PDF format for brand consistency.
  11. Attach a style guide or notes on colors, fonts, and usage rights if applicable.
  12. Deliver a high-res preview image for client approval before sending final files.
  13. Provide a PDF mockup of the illustration in context (e.g., on a t-shirt, poster, or website).
  14. Include a README file with step-by-step instructions for using the files (e.g., how to open layers).
  15. Add a license agreement or usage terms document clarifying rights and restrictions.
  16. Set up a revision policy with clear limits (e.g., 2 rounds of edits included).
  17. Confirm client?s deadline and delivery format (e.g., email, client portal, physical USB drive).
  18. Test all deliverables on client?s preferred platforms (e.g., Instagram, print shop) before handoff.
  19. Include a changelog or version history for client reference (e.g., ?v1 ? original, v2 ? adjusted colors?).
  20. Provide a contact sheet or gallery of all illustrations if delivering multiple pieces.
  21. Add a brief summary of tools used (e.g., Procreate, Adobe Illustrator, Photoshop) for transparency.
  22. Include a royalty-free font list if custom typography was used in the design.
  23. Send a follow-up email with all deliverables and a thank-you note for their business.
  24. Schedule a 15-minute call to walk the client through the files and answer any questions.
