Web Design Client Brief Generator: 40 Ready-to-Use Prompts to Secure Clear, Profitable Projects in Minutes

client brief prompts for web designers ? 40 prompts.

  1. Write the exact business goal the website must achieve (e.g., 'increase demo sign-ups by 30% in 6 months').
  2. List the three highest-value customer personas the site must speak to.
  3. Specify the exact primary action you want users to take on the homepage (e.g., 'click a sticky CTA button labeled "Book a Free Consultation"').
  4. State the minimum and maximum acceptable page load speed (e.g., 'under 2.5s on 3G, under 1.2s on Wi-Fi').
  5. Define the brand?s color palette with HEX codes (e.g., 'Primary: #0066FF, Secondary: #FF6600, Neutral: #FFFFFF').
  6. Provide the exact typography hierarchy (e.g., 'H1: 48px/700 Montserrat, H2: 36px/600 Montserrat, Body: 16px/400 Open Sans').
  7. Describe the core messaging for the hero section in 25 words or less.
  8. List the exact number of pages the website must include (e.g., 'Home, About, Services, Blog, Contact, Privacy Policy').
  9. Specify the required integrations (e.g., 'Stripe for payments, HubSpot for CRM, Zapier for automation').
  10. Define the minimum and maximum acceptable bounce rate for the homepage (e.g., '15%?25%').
  11. Provide the exact social media platforms where the brand is active (e.g., 'Instagram, LinkedIn, Twitter').
  12. State the required accessibility compliance level (e.g., 'WCAG 2.1 AA').
  13. List the exact stock imagery or illustration style the client prefers (e.g., 'minimalistic, flat-lay, neutral tones').
  14. Specify the required CMS (e.g., 'WordPress with Elementor, Webflow, or custom React build').
  15. Provide the exact payment terms and milestones (e.g., '50% upfront, 25% on design approval, 25% on launch').
  16. State the required SEO keywords for the homepage (e.g., 'best SaaS development agency, custom software solutions').
  17. Define the exact file formats for deliverables (e.g., 'Figma for designs, PNG for icons, SVG for logos').
  18. List the required third-party tools for analytics (e.g., 'Google Analytics 4, Hotjar, Microsoft Clarity').
  19. Specify the exact tone of voice for all copy (e.g., 'friendly, professional, and concise').
  20. Provide the exact domain and hosting requirements (e.g., 'domain purchased via Namecheap, hosting via SiteGround').
  21. State the required number of revisions for design mockups (e.g., '3 rounds of revisions').
  22. List the exact legal pages required (e.g., 'Terms of Service, Privacy Policy, GDPR Compliance').
  23. Specify the required mobile responsiveness breakpoints (e.g., '320px, 768px, 1024px, 1440px').
  24. Provide the exact number of calls-to-action per page (e.g., '2 per page: one hero, one sticky').
  25. Define the required favicon and app icon specifications (e.g., '512x512 PNG, transparent background').
  26. List the required performance metrics to track post-launch (e.g., 'conversion rate, average session duration, pages per session').
  27. Specify the exact number of testimonials to feature (e.g., '3 client testimonials with photos and job titles').
  28. Provide the exact email address for client feedback (e.g., 'feedback@clientname.com').
  29. State the required number of wireframe screens (e.g., '10 screens: homepage, about, services, contact, etc.').
  30. List the exact fonts to avoid (e.g., 'Comic Sans, Papyrus, Impact').
  31. Specify the required number of hero images or videos (e.g., '1 hero image, 1 background video').
  32. Provide the exact number of blog posts to include in the initial design (e.g., '5 blog posts with featured images').
  33. Define the required number of navigation menu items (e.g., '5: Home, About, Services, Blog, Contact').
  34. List the exact color codes for interactive states (e.g., 'Hover: #0055CC, Active: #0044AA').
  35. Specify the required number of team member profiles (e.g., '4 team bios with photos and roles').
  36. Provide the exact number of FAQ items to include (e.g., '10 FAQ items with expandable answers').
  37. State the required number of portfolio projects to showcase (e.g., '6 projects with images, descriptions, and client links').
  38. List the exact social media share buttons required (e.g., 'LinkedIn, Twitter, Facebook').
  39. Specify the required number of contact form fields (e.g., 'Name, Email, Message, Submit button').
  40. Provide the exact number of client-provided assets (e.g., '5 high-res images, 2 logo files, 1 brand guideline PDF').
