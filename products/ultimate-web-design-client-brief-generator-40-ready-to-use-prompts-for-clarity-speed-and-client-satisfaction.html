Ultimate Web Design Client Brief Generator: 40 Ready-to-Use Prompts for Clarity, Speed, and Client Satisfaction

client brief prompts for web designers ? 40 prompts.

  1. What is the primary goal of the website? (e.g., lead generation, online sales, brand awareness)
  2. Who is the target audience? Please describe their demographics, pain points, and online behavior.
  3. List 3 direct competitors. What do they do well, and where do they fall short in design or user experience?
  4. Describe the brand?s visual identity. Provide the logo files, color palette (hex codes), typography, and any existing style guides.
  5. Include 5 websites you love. What specifically do you like about them? (e.g., layout, color scheme, animations)
  6. Define the key pages required. (e.g., Home, About, Services, Portfolio, Blog, Contact)
  7. List any must-have features or functionality. (e.g., e-commerce, booking system, membership login)
  8. Specify any integrations needed with third-party tools. (e.g., Mailchimp, Google Analytics, CRM systems)
  9. Provide examples of preferred navigation styles. Should it be minimal, megamenu, or hamburger-style?
  10. Outline the desired user flow for the main conversion goal (e.g., homepage ? product page ? checkout).
  11. Indicate any specific design trends you want to incorporate or avoid. (e.g., dark mode, glassmorphism, retro)
  12. Provide content samples for the homepage hero section. Include headline, subheadline, and CTA text.
  13. Specify the tone of voice for written content. (e.g., professional, friendly, humorous, technical)
  14. Include any high-resolution images, icons, or graphics you already have or plan to source.
  15. State your preferred image style. (e.g., illustration, photography, abstract, minimalist)
  16. List any specific animations or micro-interactions you want. (e.g., hover effects, loading animations)
  17. Define the mobile responsiveness requirements. Should the mobile version mirror the desktop or have a simplified layout?
  18. Specify the preferred loading speed targets. (e.g., aim for under 2 seconds for the homepage)
  19. Indicate if accessibility compliance is required. (e.g., WCAG 2.1 AA, screen reader compatibility)
  20. Provide any existing customer personas or user research data to guide the UX design.
  21. List any technical constraints. (e.g., must work on IE11, needs to be built in Webflow, specific CMS requirements)
  22. Include any budget or timeline constraints upfront.
  23. Specify the preferred content management system (CMS). (e.g., WordPress, Webflow, Shopify, custom)
  24. Indicate if you need a style guide or design system created for future updates.
  25. Provide examples of preferred layouts for product/service pages (grid, masonry, carousel).
  26. List any legal or compliance requirements. (e.g., GDPR, cookie consent banners, disclaimers)
  27. Indicate if the website needs to be multilingual or support multiple currencies.
  28. Specify any SEO requirements. (e.g., keyword targets, meta description guidelines, URL structure preferences)
  29. Provide examples of successful call-to-action (CTA) buttons from other sites you admire.
  30. List any specific social media platforms that need integration or links.
  31. Indicate if you need a blog or news section with a particular layout (e.g., grid, list, featured posts).
  32. Provide any existing website analytics data or heatmaps to inform UX improvements.
  33. Specify if you need a 404 error page, maintenance page, or other utility pages designed.
  34. List any specific fonts or font weights you want to use and where to source them.
  35. Indicate if you have preferred stock photo libraries or sources for imagery.
  36. Provide examples of your brand?s existing tone in social media posts or marketing materials.
  37. Specify if you need a custom icon set designed or if you have a preferred icon library.
  38. List any specific data visualization needs. (e.g., charts, graphs, infographics)
  39. Indicate if you need a sitemap or user journey map created before the design phase.
  40. Provide any existing brand guidelines or previous design assets that should be referenced.
