Ultimate Lettering Project Handover Checklist: Deliver Pro-Level Files with Zero Stress

handover checklist for lettering artists ? 25 steps.

  1. Verify all client-provided source files (e.g., sketches, vectors, references) are included in the project folder.
  2. Export final lettering compositions in CMYK and RGB color modes for print and digital use.
  3. Provide layered source files (AI, EPS, or PSD) with all text and effects editable.
  4. Include a vector-only version of the lettering (no effects or masks) for scalability and re-editing.
  5. Save a high-resolution PNG (300 DPI) of the final lettering for quick client previews.
  6. Create a separate file with transparent background for use on any color surface.
  7. Organize all font files used in the project in a dedicated 'Fonts' subfolder.
  8. Document all custom brushes, textures, or effects created for the project.
  9. Include a style guide with hex codes, RGB/CMYK values, and Pantone matches (if applicable).
  10. Provide a clear naming convention for all files (e.g., ClientName_ProjectTitle_Date_Version).
  11. List all third-party assets (images, icons, etc.) used with licensing details and source links.
  12. Export a web-optimized JPG (72 DPI) for social media or quick sharing.
  13. Create a PDF proof with client approval for final sign-off before delivery.
  14. Include a readme.txt file with instructions on how to install fonts and use provided files.
  15. Provide a usage rights document outlining client permissions for commercial or personal use.
  16. Export an SVG file for web animations, scalability, or future edits.
  17. Include a mockup showing the lettering applied to a real-world surface (e.g., signage, packaging).
  18. Verify all file formats are compatible with the client?s software (Adobe, Procreate, etc.).
  19. Add a 'Hidden' layer in source files with notes on adjustments or client feedback incorporated.
  20. Provide a timeline or revision history log for transparency on project progress.
  21. Include a contact sheet with your branding, contact info, and service highlights for future referrals.
  22. Export a low-resolution GIF for quick client feedback sessions.
  23. Create a backup ZIP file of the entire project folder for record-keeping.
  24. Send a follow-up email with a download link, usage tips, and an open invitation for future projects.
  25. Include a feedback form link to gather client testimonials for your portfolio or website.
