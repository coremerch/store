Lettering Artist's Project Handover Checklist: Ensure Flawless Client Deliverables Every Time

handover checklist for lettering artists ? 25 steps.

  1. Verify project scope matches client?s initial brief, including style, deliverables, and timelines.
  2. Confirm all reference materials (sketches, mood boards, client examples) are organized in a single folder.
  3. Double-check client?s preferred file formats and color modes (RGB/CMYK) for final delivery.
  4. Ensure all lettering drafts are saved in both editable (AI/EPS) and flattened (PDF/PNG) formats.
  5. Label files with a consistent naming convention (e.g., 'ClientName_ProjectName_Version_Date').
  6. Include a version history log in the project folder to track revisions and client feedback.
  7. Provide a style guide (if applicable) with key typography rules, spacing, and color codes.
  8. Export high-resolution PNGs (300 DPI) for web and PDFs for print, if required.
  9. Create a vectorized version of the lettering (if applicable) with clean anchor points and no overlapping paths.
  10. Test all exported files for visual clarity and consistency across different devices and platforms.
  11. Include a readme.txt or instructions file explaining how to use the delivered assets.
  12. Provide a contact sheet showing the final lettering in context (e.g., mockups, packaging, or signage).
  13. Ensure all fonts used are either licensed for commercial use or replaced with similar free alternatives.
  14. Check that all linked images or assets in the project file are embedded to avoid missing files.
  15. Generate a list of all tools, brushes, or plugins used in the creation process for client reference.
  16. Include a licensing agreement (if applicable) outlining usage rights and limitations.
  17. Provide a backup of the project files in a separate cloud storage folder (Google Drive, Dropbox).
  18. Test the deliverables on a client?s preferred platform (e.g., social media, website, or print shop) if possible.
  19. Create a quick-start guide for clients unfamiliar with design software (e.g., how to open AI files).
  20. Include a list of recommended software or tools for further editing (if the client may need to modify the work).
  21. Ensure all text layers are expanded or outlined to prevent font compatibility issues.
  22. Provide a color palette breakdown with HEX, CMYK, and Pantone values (if applicable).
  23. Add a small watermark or copyright notice on preview images to protect intellectual property during review.
  24. Schedule a follow-up call or email to ensure the client has received and understood all deliverables.
  25. Include a feedback form or survey link to gather client satisfaction metrics post-delivery.
