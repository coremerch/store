Client-Ready Lettering Handoff Checklist: Deliver Flawless Designs Every Time

handover checklist for lettering artists ? 25 steps.

  1. Verify final artwork matches the approved sketch or draft with zero deviations in letterforms
  2. Check that all custom lettering is converted to outlines or paths for scalability
  3. Ensure kerning between letters is consistent and optically balanced
  4. Confirm tracking (letter-spacing) is uniform across all text blocks
  5. Standardize baseline alignment for all lines of text
  6. Verify that all ligatures and special character pairs are correctly spaced
  7. Check for and correct any overlapping or touching letterforms
  8. Ensure all swashes, flourishes, and decorative elements are intact and properly positioned
  9. Confirm that all color fills and strokes are within brand guidelines
  10. Check that all text is legible at 100% zoom without pixelation or distortion
  11. Export the final design in the requested file formats (AI, EPS, SVG, PNG, JPEG)
  12. Include layered files with organized groups for easy client edits
  13. Provide a color swatch palette in CMYK and RGB for print and digital use
  14. Include a style guide with font specifications, lettering weights, and usage rules
  15. Add a transparent PNG version with a clean white or transparent background
  16. Create a high-resolution mockup showcasing the lettering in context
  17. Include a low-resolution preview for quick client review
  18. Provide a README file with instructions for opening and editing files
  19. Verify that all client-provided assets (fonts, images) are properly licensed for final delivery
  20. Check file naming conventions for clarity (e.g., 'ClientName_ProjectName_Date_Version')
  21. Include a contact sheet with your name, logo, and portfolio link for future work
  22. Provide a brief usage rights document outlining client permissions and restrictions
  23. Confirm that all files are virus-free and free of hidden layers or clipping masks
  24. Double-check that all text is editable (if required) without breaking the design
  25. Send a final invoice and thank-you note with the delivered files
