The Ultimate Client Brief Generator: 40 High-Converting Prompts to Land Web Design Projects Faster

client brief prompts for web designers ? 39 prompts.

  1. What is the primary goal of the website? (e.g., sell products, generate leads, showcase portfolio, provide information)
  2. Who is the target audience for this website? (Include demographics like age, gender, profession, interests, and pain points)
  3. What are the top 3 competitors in this industry, and what design elements do they use that we should either emulate or avoid?
  4. What is the expected timeline for this project? (Break down phases: discovery, design, revisions, launch)
  5. What is the budget range for this project? (Specify if it includes design only, development, or ongoing maintenance)
  6. Are there any existing brand guidelines we must follow? (Include logo usage, color palette, typography, and tone of voice)
  7. What is the preferred style for the website? (e.g., minimalist, modern, retro, bold, playful, corporate)
  8. Should the design be responsive, and if so, what devices or screen sizes should it prioritize? (e.g., mobile-first, desktop, tablet)
  9. What are the key pages that must be included in the initial design? (e.g., Home, About, Services, Portfolio, Contact, Blog)
  10. What type of navigation structure do you envision? (e.g., mega menu, dropdown, hamburger menu, sticky header)
  11. Will there be a blog or news section? If so, how should the layout differ from other pages?
  12. Are there any specific features or functionalities required? (e.g., booking system, e-commerce, live chat, search bar, social media integration)
  13. What is the tone of voice for the content? (e.g., professional, friendly, humorous, authoritative)
  14. Should the design include any animations or micro-interactions? If so, provide examples or describe the desired effect.
  15. What is the preferred color scheme for the website? (Provide hex codes or examples of similar websites)
  16. What type of imagery will be used? (e.g., stock photos, custom illustrations, photography, abstract graphics)
  17. Are there any specific call-to-action (CTA) buttons that must be included? (e.g., 'Get a Quote,' 'Sign Up Now,' 'Learn More')
  18. Should the website include a newsletter signup form? If so, where should it be placed and what incentives should be offered?
  19. What is the desired loading speed for the website? (Provide any specific performance benchmarks or tools to use for testing)
  20. Will the website need to integrate with any third-party tools or APIs? (e.g., CRM, payment gateway, analytics, email marketing)
  21. What is the SEO strategy for this website? (Include target keywords, meta descriptions, and any existing SEO efforts)
  22. Should the design include a dark mode option? If so, provide examples of how it should look.
  23. What is the preferred font pairing for the website? (Provide font names or examples of similar websites)
  24. Are there any specific accessibility requirements? (e.g., WCAG compliance, alt text for images, keyboard navigation)
  25. Should the website include a FAQ section? If so, what questions should be answered and how should it be structured?
  26. What is the desired hierarchy for the homepage? (e.g., fold content, hero section, value proposition, testimonials)
  27. Will there be a membership or login area? If so, describe the user flow and required fields.
  28. What is the preferred layout for the about page? (e.g., team bios, company story, mission statement, timeline)
  29. Should the portfolio or gallery pages include filters or sorting options? If so, describe the desired functionality.
  30. What is the desired layout for product or service pages? (e.g., grid, list, masonry, carousel)
  31. Should the website include a testimonials or case studies section? If so, provide examples or describe the desired format.
  32. What is the preferred method for handling client feedback and revisions? (e.g., email, project management tool, in-person meetings)
  33. Are there any specific legal requirements for the website? (e.g., GDPR compliance, cookie consent, privacy policy)
  34. What is the desired approach for mobile optimization? (e.g., separate mobile site, adaptive design, responsive design)
  35. Should the website include a live chat or contact form? If so, describe the desired placement and functionality.
  36. What is the preferred method for testing the design? (e.g., A/B testing, user testing, heatmaps, analytics review)
  37. Are there any specific hosting or domain requirements? (e.g., shared hosting, dedicated server, specific domain registrar)
  38. What is the desired approach for post-launch support? (e.g., maintenance plan, hourly rate for updates, no support)
  39. What are the key performance indicators (KPIs) for measuring the success of this website? (e.g., conversion rate, bounce rate, time on page)
