Ultimate Lettering Handover Checklist: Deliver Flawless Vector Art Every Time

handover checklist for lettering artists ? 24 steps.

  1. Verify all lettering is converted to outlines (no live type remaining)
  2. Ensure all anchor points are clean and minimal (no unnecessary points)
  3. Check for overlapping paths in each letterform and merge them where possible
  4. Confirm the baseline and x-height are consistent across all characters
  5. Test kerning pairs for visual balance before final delivery
  6. Export a high-resolution PNG (300 DPI) of the final composition for client review
  7. Provide a transparent background PNG for client flexibility in backgrounds
  8. Include a layered AI/PSD file with organized groups for each word/phrase
  9. Label all groups clearly (e.g., 'Title', 'Subtitle', 'Body Text') for easy navigation
  10. Add a hidden layer with a color-coded legend explaining each group's purpose
  11. Include a PDF version of the lettering for print-ready use
  12. Provide a vector-only EPS file for scalability in third-party applications
  13. Export an SVG file for web use to ensure crisp rendering on all devices
  14. Test all exported files at 100% and 200% zoom for visual integrity
  15. Include a readme.txt file with file descriptions, software used, and version info
  16. Provide a list of all fonts used (if any live type remains) with licensing details
  17. Add a note specifying the minimum and maximum sizes the lettering should be used at
  18. Include a visual style guide (color codes, spacing specs, and alignment rules)
