Lettering Project Handover Checklist: Deliver Flawless Work Every Time

handover checklist for lettering artists ? 25 steps.

  1. Verify client?s preferred file formats (AI, EPS, SVG, PNG, JPG) for final delivery
  2. Organize files in a folder structure: /Final_Files /Original_Sketches /Reference_Materials
  3. Rename files using a clear naming convention (e.g., ClientName_ProjectName_Date_LetteringStyle_Version)
  4. Export high-resolution PNG (300 DPI, transparent background) for web/mockup use
  5. Provide vector files (AI/EPS) with all paths expanded and no clipping masks
  6. Ensure all lettering strokes are converted to outlines in vector files
  7. Include a PDF proof with color swatches used in the final design
  8. List all custom fonts or lettering styles created specifically for the project
  9. Provide a font specimen sheet showing uppercase, lowercase, and special characters
  10. Document any stylistic alternates, ligatures, or alternate glyphs used in the design
  11. Include a style guide with hex codes, RGB/CMYK values, and Pantone matches (if applicable)
  12. Export a simplified version (black and white) for easy client edits or scalability
  13. Provide a short animation or GIF of the lettering process (if client requested motion)
  14. Create a usage rights document outlining permitted uses (personal, commercial, derivatives)
  15. Include a source file with editable guides (e.g., baseline grid, x-height markers) for future reference
  16. Provide a contact sheet with before/after sketches, thumbnails, or process images
  17. Export a high-resolution JPG at 4K width for print-ready reference
  18. Document any third-party assets (textures, brushes) used and their licensing terms
  19. Include a readme.txt file with step-by-step instructions for opening/editing files
  20. Provide a version history log listing each iteration and changes made
  21. Export a web-optimized SVG with minimal path complexity for fast loading
  22. Include a mockup of the lettering in a real-world context (e.g., signage, packaging)
  23. Provide a responsive web-ready PNG at 2x resolution for retina displays
  24. Document any required software or plugins (e.g., Procreate, Illustrator scripts) for edits
  25. Include a final invoice and receipt with project details and deliverables summary
