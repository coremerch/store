The Ultimate Illustrator?s Client Handoff Checklist: Deliver Like a Pro, Get Hired Again

handover checklist for illustrators for hire ? 24 steps.

  1. Verify client?s final project brief and deadlines in writing before starting work
  2. Confirm deliverable formats (PNG, PDF, SVG, etc.) and color profiles (RGB/CMYK)
  3. Set up a project folder with client name and project title for easy access
  4. Organize source files (AI, PSD, EPS) in a dedicated ?Source? subfolder
  5. Label all layers in source files (e.g., ?Background?, ?Character?, ?Text?) for easy edits
  6. Create a ?Read Me? file listing fonts used, pantone colors (if any), and resolution specs
  7. Provide a ?Quick View? folder with low-res previews for client approval
  8. Export final illustrations at 300 DPI for print and 72 DPI for web (if applicable)
  9. Check all exported files for visual consistency and alignment with client?s brand
  10. Remove any hidden or unused layers or objects from source files before delivery
  11. Save vector files with outlines (convert text to paths) to ensure font independence
  12. Include a license agreement outlining usage rights, credit requirements, and reproduction limits
  13. Provide a usage guide for the client (e.g., minimum size for print, safe zones for text overlay)
  14. Deliver a color palette reference sheet with HEX, RGB, and CMYK values used
  15. Include a list of all licensed fonts (if not embedded) with download links or purchase info
  16. Add a timestamp or version number to files to track final deliverables
  17. Double-check file names for clarity (e.g., ?ClientName_ProjectName_IllustrationType_V1.png?)
  18. Provide a brief changelog if multiple revisions were made (e.g., ?V1: Initial draft, V2: Added shadows?)
  19. Send a final invoice with a clear breakdown of hours worked and deliverables included
  20. Schedule a post-project call or email to discuss client satisfaction and next steps
  21. Request a testimonial or case study reference if the client is happy with the work
  22. Archive the project in your portfolio or client database for future reference
  23. Update your project management tool (e.g., Trello, Asana) to mark the project as complete
  24. Send a thank-you message to the client, referencing their project and next steps
