Ultimate Client Handover Checklist for Illustrators: Ensure Flawless Deliverables & Happy Clients Every Time

handover checklist for illustrators for hire ? 25 steps.

  1. Verify client?s final approval of the illustration concept in writing before starting detailed work.
  2. Confirm file format requirements (PNG, JPEG, SVG, PDF, etc.) for final delivery.
  3. Ensure vector files (AI, EPS, SVG) are saved with all layers, groups, and paths intact.
  4. Export high-resolution raster files (minimum 300 DPI) for print-ready use if required.
  5. Provide separate transparent PNG versions (PNG-24) for web use with no background.
  6. Include a vector-based color palette (HEX, RGB, CMYK values) as a text file or swatches.
  7. Deliver source files (PSD, AI) with all adjustment layers, masks, and smart objects preserved.
  8. Check that all linked images or embedded assets are included in a ?Resources? folder.
  9. Create a ?Read Me? text file with instructions for reopening and editing files.
  10. Include a style guide (line weights, typography, color usage) if the illustration includes text.
  11. Provide a mood board or reference image collage used during the design process (if requested).
  12. Export a low-resolution preview (JPEG, 72 DPI) for client review before final delivery.
  13. Ensure all fonts used are either embedded or provided as separate files (.TTF, .OTF).
  14. Deliver a final PDF with all illustrations flattened and print-ready settings applied.
  15. Include a usage rights document outlining licensing terms (e.g., commercial, editorial, exclusive).
  16. Verify that client?s brand guidelines (colors, spacing, logo placement) are respected before finalizing.
  17. Check file naming conventions (e.g., ?ClientName_Illustration_Version_Date?) to avoid confusion.
  18. Provide separate files for different applications (e.g., social media, packaging, merchandise).
  19. Include a ?Change Log? if multiple revisions were made, detailing what was altered each time.
  20. Export a grayscale version if the client requires a monotone/duotone variation.
  21. Deliver a vector-based wireframe or sketch file if the client requested early-stage concepts.
  22. Include a ?Quick Start? guide for non-designers on how to use the files (e.g., drag-and-drop instructions).
  23. Verify that all deliverables are uploaded to a secure, organized cloud folder (Google Drive, Dropbox, etc.).
  24. Send a final invoice with a clear breakdown of services, revisions included, and payment terms.
  25. Follow up within 24 hours of delivery to confirm receipt and address any immediate questions.
