Lettering Handover Checklist: Client-Ready Deliverables for Stress-Free Final Delivery

handover checklist for lettering artists ? 25 steps.

  1. Export final lettering artwork in CMYK color mode at 300 DPI for print projects
  2. Provide a separate RGB version at 72 DPI for digital/screen use
  3. Include vector files in AI, EPS, or SVG format with all editable paths intact
  4. Deliver layered PSD files with each letter/word on its own group for easy adjustments
  5. Provide a flattened high-resolution JPG/PNG for quick client previews
  6. Include a style guide documenting font names, sizes, and spacing metrics
  7. List all used fonts with licenses and download links for client access
  8. Specify exact color codes in HEX, RGB, CMYK, and Pantone (if applicable)
  9. Include a transparent background PNG with drop shadows or effects intact
  10. Provide a simplified line-art version for merchandise or stamps
  11. Deliver a 3D mockup of the lettering applied to a product (e.g., mug, t-shirt, sign)
  12. Include a PDF proof with client?s final text and design variations
  13. Provide a custom icon set if the lettering includes stylized symbols or accents
  14. Deliver a character map or glyph legend for non-standard letterforms
  15. Include a readme file with file naming conventions and folder structure
  16. Provide a usage rights document outlining licensing terms and restrictions
  17. Deliver a source file for any custom brushes or textures used in the design
  18. Include a revision history log showing changes made during the project
  19. Provide a high-resolution background texture or paper texture file if used
  20. Deliver a custom envelope or packaging design if the lettering is for physical mail
  21. Include a social media kit with optimized lettering for profile pics, stories, and posts
  22. Provide a video or animated version of the lettering for motion graphics use
  23. Deliver a QR code linking to a digital portfolio or project showcase page
  24. Include a client feedback form template for future reference or testimonials
  25. Provide a final invoice and payment receipt in PDF format for record-keeping
