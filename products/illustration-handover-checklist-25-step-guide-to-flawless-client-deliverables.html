Illustration Handover Checklist: 25-Step Guide to Flawless Client Deliverables

handover checklist for illustrators for hire ? 24 steps.

  1. Verify all contract deliverables (files, formats, quantities) against the signed agreement before starting work.
  2. Confirm the final illustration style with the client (vector, raster, hand-drawn, digital painting) and ensure it matches the brief.
  3. Provide 3?5 style reference images or mood boards to the client for approval before finalizing the illustration.
  4. Set up a layered file structure (e.g., Layers, Groups) in your design software (Illustrator, Procreate, Photoshop) using clear, consistent naming conventions (e.g., 'BG_Sky', 'FG_Character').
  5. Use a CMYK color profile if the illustration is for print, and an RGB profile if it?s for digital use (specify this to the client).
  6. Create a color palette swatch in your software and export it as an ASE/ACO file for client use in other projects.
  7. Save a master file in the original software format (e.g., .ai, .psd, .procreate) with all layers intact for future edits.
  8. Export a flattened, high-resolution version (e.g., PNG, JPEG) at 300 DPI for print or 72?150 DPI for digital, labeled with the project name and version.
  9. Provide a vector version (e.g., .ai, .eps, .svg) of the illustration, ensuring all paths are closed and no stray anchor points exist.
  10. Include a transparent background version (PNG with alpha channel) if the illustration will overlay other designs.
  11. Generate a PDF portfolio-ready version (300 DPI, CMYK) with a white background and no crop marks for print use.
  12. Create a social media-optimized version (e.g., 1080x1080px, 72 DPI, RGB) labeled for Instagram or other platforms.
  13. Export a web-optimized version (e.g., 800?1200px wide, 72 DPI, JPEG at 60?80% quality) for quick online loading.
  14. Provide a print-ready version (300 DPI, CMYK, with bleed if needed) labeled for the printer (e.g., 'For Print?Do Not Resize').
  15. Include a 1-page style guide document with hex codes, font pairings (if text is included), and usage restrictions (e.g., 'For digital use only').
  16. Deliver a font file or embed fonts in the exported files if text is part of the illustration (check licensing restrictions).
  17. Include a README file with version history, creation date, software used, and any third-party assets (e.g., brushes, fonts) with licenses.
  18. Provide a low-resolution preview (e.g., 500px wide) for quick client review before final delivery.
  19. Label all files with the project name, date, and version (e.g., 'ProjectName_20240515_v2.ai').
  20. Include a final invoice or receipt with a breakdown of deliverables and usage rights (e.g., 'Commercial use, one-time fee').
  21. Send a follow-up email summarizing all delivered files and their purposes (e.g., 'This PNG is for your website header').
  22. Offer a 30-day post-delivery support window for minor edits or file clarifications at no extra cost.
  23. Create a backup folder with all source files, exports, and references, zipped and stored in cloud storage (Google Drive, Dropbox) with a shareable link.
  24. Provide a usage rights document outlining where and how the client can use the illustration (e.g., 'Unlimited web use, print run of 5,000 copies').
