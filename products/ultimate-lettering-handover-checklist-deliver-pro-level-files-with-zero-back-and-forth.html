Ultimate Lettering Handover Checklist: Deliver Pro-Level Files with Zero Back-and-Forth

handover checklist for lettering artists ? 24 steps.

  1. Verify project scope matches client brief and contract terms
  2. Confirm final lettering style (script, sans, serif, decorative) and weights
  3. Check baseline lettering alignment and spacing consistency across all words
  4. Ensure no overlapping or touching glyphs that break readability
  5. Export vector files with clean, single-stroke paths (no double nodes or stray points)
  6. Provide layered AI/EPS files with organized group hierarchy (words > letters > strokes)
  7. Include a flat PNG/JPG preview at 300 DPI for quick client review
  8. Deliver a PDF style guide showing correct letterforms, alternate glyphs, and usage rules
  9. Label all files with project name, date, and version number (e.g., ?BrandName_Logo_2024_v3.ai?)
  10. Embed or outline all fonts to prevent compatibility issues
  11. Remove hidden objects, clipping masks, or unused swatches from source files
  12. Provide a ?Do Not Use? sample of a poorly spaced or misaligned lettering example for reference
  13. Include kerning pairs or tracking adjustments applied in a separate layer
  14. Confirm color codes (CMYK, RGB, Pantone) match client?s brand guidelines
  15. Deliver both black-and-white and color-ready versions of the lettering
  16. Add a small notational diagram showing baseline, x-height, and cap height for scaling accuracy
  17. Include a ReadMe.txt with instructions for opening, editing, and scaling files
  18. Provide a transparent PNG of the lettering at minimum 2000px wide for web use
  19. Deliver a high-res TIFF for print applications if client requests physical output
  20. Include a modular component set (individual letters) in a separate file for custom edits
  21. Add a version with reversed paths for screen printing or laser engraving compatibility
  22. Provide a 30-second timelapse video of the creation process (optional but high-value)
  23. Include client-specific usage dos and don?ts (e.g., minimum size, safe zones, color restrictions)
  24. Send a final invoice and handover confirmation email with download links and next steps
