Web Designer's Client Brief Accelerator: 40 High-Converting Prompts to Land More Projects & Avoid Scope Creep

client brief prompts for web designers ? 40 prompts.

  1. What are the top 3 business goals this website must achieve within the first 6 months?
  2. Describe the ideal customer persona for this project. Include demographics, pain points, and online behavior.
  3. List the 3 primary competitors your website must outperform. Provide their URLs and 1-2 specific features you want to beat.
  4. What is the exact budget range for this project (including design, development, and post-launch support)?
  5. What is the desired timeline for project completion? Break it down into milestones (e.g., design, development, testing, launch).
  6. Do you have an existing brand style guide, logo files, or brand colors? If yes, share them in a single ZIP folder.
  7. What are the 3 most important user actions this website must facilitate (e.g., sign up, purchase, contact)?
  8. Provide 5 examples of websites you admire and explain what you like about each one (layout, color scheme, typography, etc.).
  9. What is the primary call-to-action (CTA) for the homepage? Should it be above the fold, and what should it say?
  10. How many main pages will this website have? List them and describe the purpose of each (e.g., Home, About, Services, Blog, Contact).
  11. Do you need a responsive design for mobile and tablet? If so, specify the breakpoints (e.g., 320px, 768px, 1024px).
  12. Will you provide the website copy (text content), or do you need assistance with copywriting?
  13. Do you have a preferred content management system (CMS)? If so, which one (e.g., WordPress, Webflow, Squarespace)?
  14. What is the tone of voice for the website?s content? (e.g., professional, friendly, humorous, minimalist)
  15. Do you need e-commerce functionality? If yes, list the products/services you plan to sell and payment gateways (e.g., Stripe, PayPal).
  16. Will you provide high-quality images and videos, or do you need help sourcing them?
  17. What is the preferred color palette for the website? Provide HEX codes for each color.
  18. What fonts do you want to use? Provide font names (e.g., Open Sans, Playfair Display) and whether they are for headings, body text, or both.
  19. Do you need a blog section? If yes, how frequently do you plan to post, and what topics will be covered?
  20. Will you need a contact form? If yes, what fields should it include (e.g., name, email, message, phone number)?
  21. Do you have a preferred layout style (e.g., minimalist, modern, retro, dark mode)? Provide 2-3 examples.
  22. What is the target audience?s preferred device for browsing (e.g., desktop, mobile, tablet)?
  23. Do you need social media integration (e.g., Instagram feed, Facebook Like button)? If yes, list the platforms.
  24. What is the expected lifespan of this website before a redesign is needed?
  25. Do you need SEO optimization for the website? If yes, list any specific keywords or phrases you want to rank for.
  26. Will you need a booking or scheduling system integrated into the website?
  27. Do you need a membership or login system? If yes, describe the user roles (e.g., admin, customer, guest).
  28. What is the primary method for generating leads (e.g., contact form, chatbot, email signup)?
  29. Do you need a sitemap or wireframe before the design phase begins? If yes, describe the structure.
  30. What is the preferred navigation style (e.g., hamburger menu, dropdown, mega menu)?
  31. Do you need a newsletter signup form? If yes, what should the incentive be (e.g., 10% off, free guide)?
  32. What is the expected load time for the website? Provide a benchmark (e.g., under 2 seconds).
  33. Do you need a multilingual feature? If yes, list the languages and whether you have translated content ready.
  34. What is the preferred method for collecting customer feedback (e.g., survey, contact form, live chat)?
  35. Do you need a 404 error page design? If yes, describe the tone and any actions you want users to take.
  36. What is the preferred method for handling 404 errors (e.g., redirect to homepage, custom message)?
  37. Do you need a favicon or app icon designed? If yes, provide the file or describe the style.
  38. What is the preferred method for handling accessibility (e.g., alt text for images, ARIA labels, color contrast)?
  39. Do you need a privacy policy and terms of service page? If yes, do you have existing content or need it drafted?
  40. What is the preferred method for post-launch support (e.g., monthly maintenance, hourly rate, retainer)?
