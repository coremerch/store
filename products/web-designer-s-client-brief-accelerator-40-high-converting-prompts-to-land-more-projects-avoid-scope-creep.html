Web Designer's Client Brief Accelerator: 40 High-Converting Prompts to Land More Projects & Avoid Scope Creep

client brief prompts for web designers ? 39 prompts.

  1. List the client?s top 3 business goals in their own words (not your interpretation).
  2. Specify the exact number of pages or sections the website must include (home, about, services, contact, etc.).
  3. Ask the client to provide 3-5 direct competitors and explain what they like/dislike about each site.
  4. Request the client?s brand style guide (colors, fonts, logo files, and usage rules).
  5. Clarify if the website will need e-commerce functionality (if yes, specify product count and payment methods).
  6. Determine if the site must be multilingual, and list the required languages.
  7. Ask for the client?s preferred content management system (e.g., WordPress, Webflow, Squarespace).
  8. Find out if the client has an existing domain and hosting, or if you?ll need to arrange this.
  9. Request the client?s target audience description (age, location, pain points, online behavior).
  10. Ask for the client?s preferred call-to-action (e.g., lead generation form, booking button, email signup).
  11. Specify the project timeline: exact start date, milestones, and hard deadline.
  12. Determine the client?s budget range (e.g., $3K?$5K, $10K?$15K) to align expectations early.
  13. Ask if the client has any design preferences (e.g., minimalist, bold colors, vintage aesthetic).
  14. Request the client?s high-priority features (e.g., interactive maps, video backgrounds, animations).
  15. Clarify if the website needs to be mobile-first, and if so, ask for mobile-specific requirements.
  16. Ask for the client?s legal requirements (e.g., GDPR compliance, cookie consent, accessibility standards).
  17. Determine if the client needs a blog or news section, and if so, how frequently it should be updated.
  18. Request the client?s social media links to ensure branding consistency across platforms.
  19. Ask if the client has any existing content (text, images, videos) or if you?ll need to create it.
  20. Clarify the client?s expectations for after-launch support (e.g., maintenance, updates, troubleshooting).
  21. Ask for the client?s preferred tone of voice for all written content (e.g., professional, casual, humorous).
  22. Determine if the client needs a booking or reservation system integrated into the site.
  23. Ask if the client has any specific SEO requirements or goals for the website.
  24. Request the client?s analytics tracking preferences (e.g., Google Analytics, Hotjar, custom dashboards).
  25. Clarify if the client needs a contact form with specific fields (e.g., dropdown menus, file uploads).
  26. Ask for the client?s preferred hosting provider or if they have any restrictions (e.g., security, uptime).
  27. Determine if the client needs a membership or login system for users.
  28. Ask if the client has any existing design assets (e.g., logos, banners) or if you?ll need to design them.
  29. Clarify the client?s expectations for loading speed and performance (e.g., under 2 seconds).
  30. Ask for the client?s preferred color palette from their brand guidelines or a mood board.
  31. Determine if the client needs a custom 404 error page or other special pages (e.g., coming soon).
  32. Ask if the client has a preferred project management tool (e.g., Trello, Asana, Slack) for collaboration.
  33. Clarify the client?s expectations for responsiveness (e.g., how many screen sizes must be tested).
  34. Ask for the client?s security requirements (e.g., SSL certificate, backup system, malware protection).
  35. Determine if the client needs a live chat or customer support integration (e.g., Zendesk, Intercom).
  36. Ask if the client has any third-party integrations in mind (e.g., Mailchimp, Salesforce, CRM tools).
  37. Clarify the client?s expectations for future scalability (e.g., easily adding new pages or features).
  38. Ask for the client?s preferred file formats for deliverables (e.g., PSD, Sketch, PDF, WordPress themes).
  39. Determine if the client needs a project handover document or training session post-launch.
