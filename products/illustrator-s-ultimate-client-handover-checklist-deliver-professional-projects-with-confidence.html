Illustrator's Ultimate Client Handover Checklist: Deliver Professional Projects with Confidence

handover checklist for illustrators for hire ? 25 steps.

  1. Verify client?s preferred file formats (AI, EPS, PDF, PNG, SVG) and confirm version compatibility.
  2. Ensure all vector files use outlined fonts (no missing typefaces).
  3. Export raster versions at 300 DPI minimum for print-ready files.
  4. Create a 'Read Me' text file with usage rights, credits, and contact info.
  5. Organize files in a clearly labeled folder structure (e.g., 'Final_Versions', 'Source_Files').
  6. Check file naming conventions follow client?s requested format (e.g., 'ProjectName_IllustrationType_V1').
  7. Embed all linked images or replace with embedded copies to avoid broken links.
  8. Set up color profiles (CMYK for print, sRGB for digital) and include profile in filenames.
  9. Provide alternate color variations (monochrome, grayscale) if requested.
  10. Include a style guide or color codes in a separate text file for future reference.
  11. Deliver layered source files (PSD, AI, or indd) with organized layer groups and named layers.
  12. Export transparent backgrounds (if applicable) as PNG-24 with alpha channels.
  13. Include a low-resolution preview (JPEG) for quick client review before final delivery.
  14. Confirm client?s preferred delivery method (email, cloud link, FTP, or project management tool).
  15. Set expiration dates on shared links (e.g., Dropbox, Google Drive) for security.
  16. Provide a brief invoice or receipt with project details, payment terms, and due date.
  17. Send a follow-up email summarizing delivered files and next steps.
  18. Document any client feedback incorporated and file versions updated in a change log.
  19. Include a license agreement (e.g., commercial, personal, editorial) if custom work.
  20. Provide high-res print-ready files separately from web-optimized versions.
  21. Export scalable vector logos or icons in multiple sizes (e.g., 512x512, 256x256).
  22. Attach a project completion summary with deliverables, deadlines met, and revision count.
  23. Offer a 30-day post-delivery support window for minor adjustments (if agreed).
  24. Include social media-ready files (e.g., Instagram Stories, Twitter headers) if part of scope.
  25. Send a thank-you note with a link to your portfolio or newsletter for future projects.
