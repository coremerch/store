Web Design Client Brief Generator: 40 Ready-to-Use Prompts to Streamline Onboarding & Boost Client Satisfaction

client brief prompts for web designers ? 40 prompts.

  1. Ask the client to describe their business in 3 sentences or less, including their core product or service.
  2. Request a list of 3-5 direct competitors the client admires, with specific examples of what they like about each.
  3. Ask the client to share their top 3 business goals for the website project (e.g., increase leads, improve brand awareness, sell products).
  4. Request the client?s target audience demographics (age, location, interests, pain points) in bullet points.
  5. Ask the client to provide a list of 3-5 websites they love and explain why each inspires them.
  6. Request the client?s brand colors (hex codes) and primary brand fonts (name and Google Fonts link if applicable).
  7. Ask the client to share their logo files in vector format (AI, EPS, SVG) and any brand style guidelines they have.
  8. Request the client?s preferred tone of voice for website copy (e.g., professional, friendly, technical, humorous).
  9. Ask the client to list 3-5 key features or functionalities their website must include (e.g., contact form, e-commerce, blog).
  10. Request the client?s timeline for the project, including key milestones (e.g., design drafts, development, launch date).
  11. Ask the client if they have an existing website, and request a link to review it for style and functionality insights.
  12. Request the client?s budget range for the project (e.g., under $2,000, $2,000?$5,000, $5,000?$10,000).
  13. Ask the client to specify any third-party integrations needed (e.g., Mailchimp, Shopify, WordPress plugins).
  14. Request the client?s preferred website structure (e.g., single-page, multi-page, parallax scrolling) with a rough sitemap outline.
  15. Ask the client if they need a mobile-responsive design and if they have specific mobile design preferences.
  16. Request the client?s preferred image style (e.g., illustrations, photography, abstract, minimalist) and examples of each.
  17. Ask the client to provide a list of 3-5 must-have pages (e.g., Home, About, Services, Contact) and their purpose.
  18. Request the client?s preferred call-to-action (CTA) buttons (e.g., ?Buy Now,? ?Get a Quote,? ?Learn More?) and their color scheme.
  19. Ask the client if they have a style guide or brand book, and request a copy if available.
  20. Request the client?s social media profiles (links) to ensure website integration and cross-promotion opportunities.
  21. Ask the client if they need a content management system (CMS) and which one they prefer (e.g., WordPress, Squarespace, Webflow).
  22. Request the client?s preferred navigation style (e.g., hamburger menu, dropdown, mega menu) and placement (horizontal/vertical).
  23. Ask the client to share any existing marketing materials (brochures, business cards) for design consistency.
  24. Request the client?s SEO goals (e.g., improve search rankings, target specific keywords, local SEO focus).
  25. Ask the client if they have a domain name and hosting provider, or if they need assistance setting these up.
  26. Request the client?s preferred loading speed expectations (e.g., under 2 seconds, under 5 seconds) and performance benchmarks.
  27. Ask the client to specify any accessibility requirements (e.g., WCAG compliance, alt text for images, keyboard navigation).
  28. Request the client?s preferred header and footer designs (e.g., full-width, minimal, sticky header).
  29. Ask the client if they need a blog or news section, and request their preferred blog layout and features (e.g., categories, search).
  30. Request the client?s preferred hero section design (e.g., full-screen, split-screen, carousel) and content requirements (e.g., headline, subhead, CTA).
  31. Ask the client if they need a contact form, and request the fields they want included (e.g., name, email, message, file upload).
  32. Request the client?s preferred color palette variations (e.g., light mode vs. dark mode, accent colors) for different sections.
  33. Ask the client to share any testimonials, case studies, or client logos they want featured on the website.
  34. Request the client?s preferred typography hierarchy (e.g., H1, H2, H3 styles, font sizes, line heights).
  35. Ask the client if they need a pricing or service table, and request the structure and content they want included.
  36. Request the client?s preferred animation or micro-interaction style (e.g., hover effects, parallax, transitions) for the website.
  37. Ask the client if they need a newsletter signup form, and request the placement and design preferences.
  38. Request the client?s preferred favicon and social media sharing image (e.g., Open Graph image) dimensions and styles.
  39. Ask the client if they need a 404 error page or custom error pages, and request their preferred design and messaging.
  40. Request the client?s preferred error message handling (e.g., inline validation, pop-up alerts) for forms and interactions.
