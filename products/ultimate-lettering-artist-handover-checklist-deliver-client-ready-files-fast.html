Ultimate Lettering Artist Handover Checklist: Deliver Client-Ready Files Fast

handover checklist for lettering artists ? 25 steps.

  1. Include all original vector files in .ai or .eps format with editable paths and anchor points
  2. Provide a layered .psd (Photoshop) file for any rasterized elements or mockups
  3. Save each final lettering piece as a high-resolution PNG (300 DPI, transparent background)
  4. Export a JPEG version (RGB, 300 DPI) for quick client previews in email
  5. Create a PDF proof with multiple layout options and color variations for approval
  6. Deliver a style guide document listing all fonts used (names, weights, licenses)
  7. Include a color palette breakdown with CMYK, RGB, HEX, and Pantone (if applicable) values
  8. Provide a typography hierarchy guide showing point sizes, leading, and tracking
  9. Send a swatch library file (.ase) for easy color matching in Adobe apps
  10. Include a brief usage rights document outlining permitted and restricted uses
  11. Provide a vector-based mockup of the lettering on a realistic surface (wood, paper, wall)
  12. Include a non-vectorized version (flattened) for clients using only basic editing tools
  13. Save all custom brushes or texture files used in the project in a dedicated folder
  14. Provide a font substitution list with free alternatives for clients without licensed fonts
  15. Include a step-by-step guide for recreating the lettering in other design software
  16. Send a final invoice with payment terms, project scope, and revision limits clearly stated
  17. Provide a contact sheet with high-res images of all alternate compositions considered
  18. Include a metadata file (.txt or .json) with project details, client name, and designer credits
  19. Save a compressed ZIP folder containing all deliverables for easy client download
  20. Provide a short video tutorial (MP4, 720p) demonstrating how to edit or resize the lettering
  21. Include a social media kit with optimized versions for Instagram, Facebook, and LinkedIn
  22. Send a client feedback form with clear instructions on how to provide revisions
  23. Include a licensing agreement template for clients who want to purchase extended usage rights
  24. Provide a list of recommended tools or services for further customization (e.g., Procreate, Illustrator plugins)
  25. Include a thank-you note with links to your portfolio, social media, and referral program (if applicable)
