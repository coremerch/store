The Ultimate Lettering Handover Checklist: Deliver Professional Designs Clients Will Love

handover checklist for lettering artists ? 25 steps.

  1. Export all lettering in high-resolution vector format (AI, EPS, SVG).
  2. Ensure all vectors are clean with no stray points or overlapping paths.
  3. Provide a separate layer with all lettering elements grouped and labeled.
  4. Include a backup file with all original lettering strokes intact (e.g., Procreate, Illustrator file).
  5. Deliver a high-resolution raster preview (PNG, 300 DPI) for client review.
  6. Create a transparent PNG version of the lettering for easy overlay on other designs.
  7. Provide a white-background PNG for immediate client use in print materials.
  8. Include a PDF proof with lettering overlaid on the final design mockup.
  9. List all fonts used in the project with download links or licensing details.
  10. Embed or outline all fonts to prevent missing font issues.
  11. Provide color codes (HEX, CMYK, RGB) for all lettering elements used.
  12. Include a color palette reference sheet for the entire design project.
  13. Deliver a style guide documenting lettering techniques (e.g., pressure sensitivity, stroke consistency).
  14. Provide a breakdown of spacing adjustments (tracking, kerning) applied to the lettering.
  15. Include a version with and without decorative elements (e.g., flourishes, ligatures) for versatility.
  16. Provide a simplified monochrome version for easy replication in different materials.
  17. Deliver a 3D mockup showing the lettering applied to a physical surface (e.g., mug, sign, packaging).
  18. Include a short video tutorial (MP4 or GIF) demonstrating how to use the lettering in design software.
  19. Provide a client-ready usage guide for applying the lettering in various software (Photoshop, Canva, etc.).
  20. Include a list of recommended tools and materials for hand-lettering the design if applicable.
  21. Provide a contact sheet with close-up views of intricate lettering details for reference.
  22. Deliver a print-ready test file with bleed and trim marks for large-scale applications.
  23. Include a checklist for the client to verify print quality before mass production.
  24. Provide a license agreement outlining usage rights, modifications, and attribution requirements.
  25. Offer 24-hour post-delivery support for any technical or design-related questions.
