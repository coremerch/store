Ultimate Client Handoff Checklist: From Lettering Art to Flawless Delivery

handover checklist for lettering artists ? 25 steps.

  1. Verify client?s preferred file format (AI, EPS, SVG, PNG, JPEG) and resolution (300 DPI for print, 72 DPI for web).
  2. Export vector files with all artboards and layers intact, labeled as 'Final_Version_[Date].ai'.
  3. Embed or outline all custom fonts to prevent font substitution issues.
  4. Provide a separate folder with outlined font versions for each design.
  5. Include a style guide with color codes (HEX, CMYK, RGB), font sizes, and spacing specifications.
  6. Deliver a PDF proof with all final artwork, including mockups if applicable.
  7. Confirm all client-provided assets (images, logos) are properly licensed and included.
  8. Name files using a consistent naming convention (e.g., 'ClientName_Project_Artboard_Format').
  9. Set up a shared cloud folder (Google Drive, Dropbox) with read-only access for client review.
  10. Create a version history log documenting changes made during revisions.
  11. Provide a contact sheet with high-resolution images of the final artwork for quick reference.
  12. Include a readme.txt file with instructions on how to use the files (e.g., 'Open in Illustrator, drag to desktop').
  13. Export separate PNG/JPEG files for social media posts, optimized for each platform (Instagram, Facebook, etc.).
  14. Label all files with a watermark (if required) to prevent unauthorized use before payment.
  15. Include a license agreement outlining usage rights, attribution requirements, and commercial use terms.
  16. Deliver a high-resolution print-ready PDF with bleeds and crop marks if applicable.
  17. Provide raw scan files (if working from hand-lettered originals) in TIFF or high-res JPEG format.
  18. Create a mockup showing the lettering applied to the intended product (e.g., t-shirt, mug, poster).
  19. Send a final invoice with payment instructions and a thank-you note for their business.
  20. Offer a 30-day follow-up email to ensure client satisfaction and address any issues.
  21. Include a link to a tutorial or guide on how to edit vector files if requested by the client.
  22. Provide a list of recommended printers or production partners if the client needs physical copies.
  23. Deliver a summary of all services rendered and hours billed for transparency.
  24. Archive a backup of all project files (including client communications) for 1 year after completion.
  25. Send a personalized thank-you note or small branded gift to encourage repeat business.
