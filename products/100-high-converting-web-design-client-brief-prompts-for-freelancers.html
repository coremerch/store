100+ High-Converting Web Design Client Brief Prompts for Freelancers

client brief prompts for web designers ? 40 prompts.

  1. Define the primary goal of the website (e.g., lead generation, e-commerce, portfolio display) in one sentence.
  2. List the top 3 competitors and describe what makes their websites effective or ineffective.
  3. Identify the target audience by creating a detailed buyer persona including demographics, pain points, and online behavior.
  4. Specify the key performance indicators (KPIs) the client wants to track (e.g., bounce rate, conversion rate, time on page).
  5. Describe the brand?s visual identity including color palette, typography, and logo usage guidelines.
  6. Outline the client?s preferred tone of voice (e.g., professional, playful, minimalist, corporate) for all written content.
  7. Provide examples of 3-5 websites the client likes and explain what they admire about each design.
  8. List the essential pages the website must include (e.g., Home, About, Services, Contact, Blog).
  9. Specify the desired layout style (e.g., grid-based, asymmetrical, card-based, single-page scroll).
  10. Determine whether the website needs to be mobile-first, desktop-first, or fully responsive in its design approach.
  11. Clarify the navigation structure including main menu items, dropdown menus, and footer links.
  12. Detail any specific features required (e.g., contact forms, image sliders, video backgrounds, e-commerce integration).
  13. Specify the preferred content management system (CMS) and whether the client needs training on using it.
  14. List any third-party integrations needed (e.g., Mailchimp, Google Analytics, CRM tools, social media feeds).
  15. Describe the client?s expectations for page load speed and performance optimization.
  16. Provide the client?s brand guidelines including logo usage, spacing rules, and do?s and don?ts for visual elements.
  17. Specify the number of stock photos or custom illustrations the client expects to include on the website.
  18. List any legal requirements or compliance standards the website must adhere to (e.g., GDPR, ADA, CCPA).
  19. Determine the client?s budget range for design, development, and ongoing maintenance.
  20. Outline the project timeline including key milestones (e.g., wireframes, design mockups, development, launch).
  21. Specify whether the client needs a style guide or design system created for future use.
  22. List any existing assets the client can provide (e.g., logos, brand guidelines, content, images).
  23. Clarify the client?s expectations for SEO optimization (e.g., on-page SEO, keyword strategy, meta descriptions).
  24. Specify if the client requires multilingual support or multiple currency options for an e-commerce site.
  25. Define the client?s preferred hosting provider and domain registrar, if they have one in mind.
  26. List any specific security features required (e.g., SSL certificates, regular backups, malware scanning).
  27. Determine whether the client needs a blog or news section and how often it should be updated.
  28. Specify the client?s expectations for accessibility (e.g., color contrast, alt text for images, keyboard navigation).
  29. List any animations or micro-interactions the client wants to include (e.g., hover effects, loading animations).
  30. Clarify the client?s stance on pop-ups, overlays, or other intrusive elements that might affect user experience.
  31. Specify the desired typography hierarchy including heading styles, font pairs, and body text sizing.
  32. Determine whether the client needs a custom 404 page, error messages, or other user-friendly fallback pages.
  33. List any specific animations or transitions the client wants (e.g., fade-in effects, parallax scrolling).
  34. Clarify the client?s expectations for cross-browser compatibility and testing requirements.
  35. Specify if the client needs a content migration plan from an existing website or CMS.
  36. List any social media links or social sharing buttons that must be included on the site.
  37. Determine whether the client requires a newsletter signup form or email capture functionality.
  38. Specify the client?s expectations for analytics setup including heatmaps, session recordings, or A/B testing tools.
  39. List any specific design trends the client wants to incorporate (e.g., dark mode, glassmorphism, neumorphism).
  40. Clarify the client?s expectations for future scalability and ease of updates.
