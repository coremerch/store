  1. Verify project scope matches client?s signed agreement (scope, deliverables, revisions).

  6. Export raster files (PNG/JPG) at the highest resolution client requested (e.g., 300 DPI, 4K).
  7. Include layered PSD files if client requested hand-drawn/composite elements.
  8. Save a flattened version of each file for quick client previews (JPG/PNG).

  10. Include all custom brushes, swatches, and fonts used in the project (if client needs to edit).
  11. Document any non-standard fonts with installation instructions or provide outlines.
  12. List all licensed assets (stock images, fonts) with links to licenses in a readme file.
  13. Create a style guide (1-pager) with color codes (HEX, CMYK, RGB), font hierarchy, and usage rules.
  14. Provide a mood board or reference images used during the design process (if applicable).
  15. Include a contact sheet with small previews of all final illustrations for quick approval.
  16. Verify all text elements are converted to outlines or provided as editable text files (if requested).
  17. Check that all hidden layers/paths are cleaned up in vector files (no stray anchor points).
  18. Test all exported files by opening them in multiple software (Adobe Illustrator, Photoshop, Preview).
  19. Ensure client?s logo (if included) is provided in vector format with clear usage guidelines.
  20. Include a project summary document with client name, date, project name, and next steps.
