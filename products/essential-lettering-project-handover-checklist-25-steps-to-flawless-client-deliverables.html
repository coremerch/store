Essential Lettering Project Handover Checklist: 25 Steps to Flawless Client Deliverables

handover checklist for lettering artists ? 25 steps.

  1. Verify client contact details and preferred communication method for post-project questions.
  2. Confirm project scope, deliverables, and timeline with the client in writing.
  3. Double-check contract terms, payment schedule, and final deliverable expectations.
  4. Ensure all vector files are saved in the correct format (AI, EPS, SVG, PDF).
  5. Provide high-resolution raster exports (PNG, JPG) in 300 DPI for print or 72 DPI for web.
  6. Include all original lettering sketches, rough drafts, and final compositions in a labeled folder.
  7. Organize files with clear naming conventions (e.g., 'ProjectName_01_FinalLettering.ai').
  8. Supply font files or licenses used in the project (if custom typography was created).
  9. Include a style guide documenting typography hierarchy, spacing, and color codes (HEX/RGB/CMYK).
  10. Provide a usage rights document outlining client permissions (commercial, personal, derivative works).
  11. Send a final invoice with payment instructions and due date clearly stated.
  12. Confirm receipt of final payment before releasing all source files and materials.
  13. Create a backup of all project files in a cloud storage (Google Drive, Dropbox) with shared access.
  14. Export all deliverables in both grayscale and color versions if applicable.
  15. Include a readme.txt file with step-by-step instructions for opening and editing files.
  16. Provide color swatches in Pantone, HEX, RGB, and CMYK values for consistency.
  17. Supply alternate versions (e.g., monogram, reversed out, simplified lockup) if requested.
  18. Verify that all client-provided assets (images, logos) are properly licensed and credited.
  19. Include a watermark-free preview of the final lettering for client approval before final delivery.
  20. Document all client feedback and revisions made during the project timeline.
  21. Send a thank-you email with a link to feedback forms for post-project reviews.
  22. Archive project files in a dedicated folder labeled with the client name and project date.
  23. Ensure all social media assets (profile pics, banners) are optimized for platform requirements.
  24. Provide a list of recommended tools (fonts, software) for future modifications by the client.
  25. Include a contact card or link to your portfolio/website for future inquiries or referrals.
