The Solo Designer?s Winning Client Brief Toolkit: 40 Ready-to-Use Prompts to Land High-Paying Projects & Avoid Scope Creep

client brief prompts for agency escapees going solo ? 40 prompts.

  1. List the exact business goals your client wants to achieve with this project (e.g., increase online sales by 30%, reduce customer support tickets by 25%).
  2. Identify the target audience with demographics: age range, location, income level, education, and professional role.
  3. Specify the primary and secondary KPIs the client will use to measure the success of this design project.
  4. Clarify the budget range the client has allocated for this project (e.g., $5K?$10K, $10K?$25K).
  5. State the project timeline including the kickoff date, key milestones, and final delivery deadline.
  6. List the names and roles of all stakeholders who will review and approve the design work.
  7. Define the brand voice the client wants reflected in the design (e.g., professional, playful, minimalist, bold).
  8. Provide examples of 3?5 design styles or aesthetics the client likes and dislikes (include links or screenshots).
  9. Confirm whether the client has existing brand guidelines (color palette, typography, logo usage, imagery style) and request to review them.
  10. Specify the platforms where the final design will be used (e.g., website, mobile app, social media, print collateral).
  11. Clarify if the client needs responsive design adaptations (e.g., desktop, tablet, mobile).
  12. Ask for the client?s preferred file formats for delivery (e.g., .ai, .psd, .pdf, .svg).
  13. Request access to any existing assets (logos, images, content) the client plans to use in the project.
  14. Inquire about any third-party integrations required (e.g., payment gateways, CRM tools, APIs).
  15. Determine if the client needs SEO optimization in the design (e.g., meta tags, alt text, structured data).
  16. Ask if the client requires accessibility compliance (e.g., WCAG 2.1 AA standards, screen reader compatibility).
  17. Clarify the client?s expectations for post-launch support (e.g., bug fixes, updates, training sessions).
  18. Request a list of competitors the client wants to differentiate from in the design approach.
  19. Ask for the client?s top 3 must-have features or elements that must appear in the final design.
  20. Specify the tone of the copy (e.g., formal, casual, humorous, technical) and provide examples of preferred copy styles.
  21. Clarify if the client has any legal or regulatory requirements (e.g., copyright, GDPR compliance, disclaimers).
  22. Ask if the client needs to include any specific cultural or regional sensitivities in the design.
  23. Request the client?s preferred communication method and frequency (e.g., weekly Slack updates, bi-weekly Zoom calls).
  24. Inquire about the client?s internal tools or software they use for project management (e.g., Trello, Asana, Monday.com).
  25. Ask if the client has a preferred project management or collaboration workflow they?d like you to follow.
  26. Clarify the client?s expectations for revisions (e.g., number of rounds, feedback format, turnaround time).
  27. Request a list of any existing design assets the client dislikes or wants to avoid replicating.
  28. Ask if the client needs to include any interactive elements (e.g., animations, hover effects, micro-interactions).
  29. Specify the client?s preferred color palette and ask if they have any color preferences or restrictions (e.g., brand colors only).
  30. Clarify if the client needs to incorporate any specific imagery or photography styles (e.g., illustrations, stock photos, custom photos).
  31. Ask if the client has a preferred typography hierarchy (e.g., headings in Gotham, body in Open Sans).
  32. Request the client?s preferred layout grid system or design framework (e.g., 12-column grid, 8-point grid system).
  33. Clarify if the client needs to include any data visualization or infographic elements in the design.
  34. Ask if the client has a preferred method for user testing or feedback collection post-design (e.g., Hotjar, UserTesting.com).
  35. Inquire about the client?s social media presence and ask if they need design templates for specific platforms (e.g., Instagram Stories, LinkedIn posts).
  36. Request the client?s preferred method for handoff (e.g., cloud storage, FTP, email, physical drive).
  37. Ask if the client needs to include any gamification elements (e.g., badges, progress bars) in the design.
  38. Clarify if the client has any existing analytics tools (e.g., Google Analytics) they want the design to integrate with.
  39. Ask for the client?s preferred method for handling feedback and revisions (e.g., Figma comments, annotated PDFs, email threads).
  40. Inquire about the client?s long-term vision for the project (e.g., scalability, future updates, multi-phase rollout).
