Ultimate Lettering Handover Checklist: Ensure Flawless Client Deliverables Every Time

handover checklist for lettering artists ? 25 steps.

  1. Verify all client-provided references (fonts, sketches, mood boards) are attached and approved in writing.
  2. Check that the final lettering style matches the agreed-upon brief (e.g., hand-drawn, digital vector, illustrative).
  3. Confirm all letterforms are proportionally balanced and visually consistent across the entire piece.
  4. Ensure no unintended overlaps, gaps, or collisions between letters and other design elements.
  5. Validate that all kerning adjustments are applied and visually harmonious at the intended size.
  6. Export the lettering as a vector file (AI, EPS, or SVG) with all paths outlined and no live type.
  7. Provide a high-resolution raster preview (PNG or JPEG) at 300 DPI for quick client approval.
  8. Include a transparent background version of the raster preview for easy integration into mockups.
  9. Deliver a layered working file (PSD or AI) with organized groups (e.g., 'Base Lettering', 'Effects', 'Guides').
  10. Save all custom brushes, textures, or effects used in a separate 'Assets' folder for reuse.
  11. Include a style guide (PDF) with hex codes, typography hierarchy, and usage rules for the lettering.
  12. Provide a scalable vector version (SVG) optimized for web use if digital applications are required.
  13. Document all color codes (RGB, CMYK, Pantone) used in the lettering for print applications.
  14. Include a 'Read Me' text file with file naming conventions, version history, and contact details.
  15. Ensure all linked images or external assets are embedded or provided in a separate 'Resources' folder.
  16. Check file compatibility with client?s preferred software (e.g., Illustrator, Procreate, Canva).
  17. Provide alternate versions (e.g., uppercase, lowercase, condensed, expanded) if requested in the brief.
  18. Include a 'Before & After' comparison image showing the evolution from sketch to final lettering.
  19. Export a clean, single-color version (e.g., black) for monochrome applications or engraving.
  20. Provide a social media-ready version (e.g., Instagram-friendly aspect ratio with transparent background).
  21. Include a 'Do?s and Don?ts' guide for scaling, spacing, and color application to prevent misuse.
  22. Verify that all client-supplied trademarks, logos, or proprietary elements are used correctly and legally.
  23. Attach a signed copyright transfer agreement or usage license if the work is for commercial reproduction.
  24. Offer a 30-minute virtual handover session to walk the client through the files and answer questions.
  25. Provide a backup folder with all original sketches, drafts, and unused variations for future reference.
