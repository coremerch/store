The Ultimate Client Handover Checklist for Lettering Artists: Ensure Flawless Delivery & Happy Clients Every Time

handover checklist for lettering artists ? 25 steps.

  1. Verify client?s preferred file formats (AI, EPS, SVG, PNG, JPG) and deliver all requested formats in a single ZIP file
  2. Include a README.txt file with project name, date, creator name, and contact information
  3. Organize files into a clear folder structure (e.g., ?01_Final_Vectors?, ?02_Rasters?, ?03_Source_Files?, ?04_Extras?)
  4. Provide a vector file (AI/EPS) with all lettering layers intact and named descriptively (e.g., ?Main_Headline_Outline?, ?Shadow_Drop_Shadow?)
  5. Export a flattened PNG/JPG at 300 DPI for client review or web use, with transparent background if applicable
  6. Create a high-resolution PDF with all variations (e.g., color, black & white, line art) for easy sharing
  7. Include a mockup file (PSD) showing the lettering in a realistic context (e.g., t-shirt, poster, packaging) if applicable
  8. Provide a style guide (PDF) with font names, sizes, color codes (HEX, CMYK, RGB), and spacing rules (tracking, leading)
  9. List all custom brushes or tools used in the project and include them in a ?Brushes? folder for future edits
  10. Export a web-optimized PNG at 72 DPI (max 2000px width) for quick client approval or social media use
  11. Include a ?How to Use? guide (PDF) with step-by-step instructions for opening, editing, and customizing files in Adobe Illustrator
  12. Check that all text is converted to outlines (paths) to avoid font compatibility issues
  13. Test all files by opening them on a different computer to ensure no corruption or missing assets
  14. Add a watermark or small logo in a corner of raster files if the project is still in progress or for promotional use
  15. Provide a ?Changelog? document listing any revisions made during the project (dates, changes, client feedback)
  16. Include a ?Fonts Used? document with names and download links for any premium or custom fonts used
  17. Create a ?Color Palette? document with HEX, RGB, and CMYK values for all colors used in the lettering
  18. Export a scalable SVG file for web developers or clients who need vector graphics for digital platforms
  19. Provide a ?Troubleshooting? guide (PDF) for common issues like missing fonts, linked files, or file corruption
  20. Include a ?Final Checklist? document summarizing all delivered materials and next steps for the client
  21. Add a ?Licensing & Usage Rights? document outlining what the client can and cannot do with the files (e.g., commercial use, print runs)
  22. Provide a ?Quick Preview? JPEG at 1000px width for instant client approval without opening large files
  23. Organize all client feedback and your responses into a ?Communication Log? (PDF) for future reference
  24. Include a ?Bonus Assets? folder with extras like alternate compositions, color swatches, or additional lettering styles
  25. Send a follow-up email with a thank-you note, delivery confirmation, and instructions for accessing the files (e.g., Google Drive, Dropbox link)
